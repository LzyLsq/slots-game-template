# L01 · Slot 大厅与账户首页模板

- 模板编号：`L01`
- 当前版本：`1.0.3`
- 状态：`TEMPLATE_READY`
- 技术栈：Cocos Creator 3.8.8 + TypeScript
- 设计分辨率：750 × 1334 竖屏
- 页面：登录、注册、首页、商店、排行榜、奖励、账户
- 数据：本地演示数据，可替换为服务端 API
- 目标：作为多个 Slot 游戏共用的大厅、账户与运营入口
- 首页图片动效：Banner 呼吸漂浮、卡片按 0.8 秒节拍轮流弹起、分类牌/徽章/金币/底栏图标错峰动画
- 输入框：登录与注册页原生输入层、文字和点击区域统一垂直居中
- 图片布局：首页卡片、底栏图标、商店商品图全部按源图宽高比显示，不再拉伸
- 账户与商店：完整资料中心、图片化功能入口、六档金币商品与演示购买反馈

本模板与具体 Slot 玩法解耦。`L01` 负责大厅与账户壳，`S01` 等模板负责实际游戏玩法。
