# L01 · Slot 大厅与账户首页模板

基于 Cocos Creator 3.8.8 + TypeScript 的独立大厅母模板。它参考了 `minigame_customize` 的首页信息架构，并复用了该项目中由用户提供的首页背景、Banner、游戏卡片和头像素材。

## 已实现

- 登录、注册、游客进入
- 本地多账户与登录状态持久化
- 用户名、密码、确认密码校验
- 注册头像选择与账户页头像切换
- 首页活动 Banner、玩法分类、2×2 游戏入口
- 六档金币商品、余额栏、演示购买反馈的完整商店页
- 顶部头像、用户名与金币余额
- 动态排行榜与当前玩家排序
- 七日奖励、每日领取与金币写入
- 账户资料、统计、设置和退出登录
- HOME / STORE / RANK / REWARDS / ACCOUNT 图片化底部导航与滑动高亮
- 页面淡出、方向滑移、淡入的连续切换过渡
- 卡片错峰弹性入场、悬浮、按钮回弹和金色环境粒子
- 复刻参考首页的图片节拍：登录后 0.5 秒启动，每 0.8 秒轮流强调一张游戏图片
- Banner、图片金币、分类图片、HOT/NEW 徽章、顶部金币及底栏图片的独立错峰动效
- 专用登录舞台、顶部栏、金币栏、分类牌、排行奖牌、奖励与账户面板素材
- 金色雕花登录/注册按钮、专用 COLLECT 奖励按钮、账户功能图片按钮
- 登录与注册输入框支持真实点击输入、密码遮罩及正确的编辑态对齐
- Web 原生输入层使用固定 58px 行高和零垂直内边距，激活输入时仍保持居中
- 首页游戏图、商品图与导航图片按原始宽高比布局，避免人物和文字被压扁
- 账户页包含完整资料卡、数据统计、收件箱、成就与图片化账户中心

## 演示账号

```text
用户名：player
密码：123456
```

也可以注册新账号，或点击 `PLAY AS GUEST`。

## 打开方式

1. 使用 Cocos Creator 3.8.8 导入本目录。
2. 打开 `assets/scenes/Main.scene`。
3. 点击浏览器预览。

Web Mobile 构建产物位于 `build/web-mobile`。源码模板压缩包位于桌面的 `CocosSlot首页Template-L01-v1.0.3.zip`。

## 数据边界

当前登录、注册、排行和奖励使用 `localStorage`，适合 UI 模板、离线原型与演示，不是正式服务器账户系统。正式产品接入后端时，应替换账户存储、密码处理、排行榜和奖励接口；不要在客户端明文保存真实用户密码。

## 接入游戏

游戏卡片点击目前显示“入口已就绪”提示。后续可把卡片回调替换为：

- `director.loadScene()` 进入同一 Cocos 工程内的游戏场景；
- 打开已安装的原生游戏模块；
- 加载远程 Asset Bundle；
- 跳转独立 Web 游戏地址。

建议把本模板编号固定为 `L01`，具体 Slot 玩法继续使用 `S01`、`S02` 等编号区分。
