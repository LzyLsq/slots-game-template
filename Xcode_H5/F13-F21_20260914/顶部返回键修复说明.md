# 顶部返回键安全区修复

日期：2026-09-15。

范围：F13、F14、F15、F17、F18、F19、F20、F21。目录无 F16。

每个项目修改两处：

- `Fxx_H5/assets/main/index.js`：SafeAreaAdapter 改读随包引擎的 `screen.safeAreaEdge`，将设备像素边距换算为设计坐标；不再读取未定义的 `screen.safeArea`。
- `Fxx_H5/style.css`：将 CSS `env(safe-area-inset-*)` 接入引擎读取的四个 `--safe-*` 变量。

顶部返回、规则、声音按钮沿用原布局公式，现在能够得到非零的正确安全区。没有修改图片、登录、支付、商品或钱包逻辑。没有按设备型号写死偏移，也没有缩放整个 WebView。

验证：8 个生成 JS 均通过 Node 语法检查。直接执行每份生成代码中的 SafeAreaAdapter 模块，在模拟屏幕参数下验证刘海竖屏、无刘海及横屏安全区。414 点宽、顶部 44 点安全区的场景中，顶部按钮点击区域上沿为 50.9 点。该验证不是 iPhone 真机触摸测试。

修改前的 16 个文件备份在同目录 `修改前备份-顶部安全区-20260915-1789451918800`，按原相对路径保存。

重新用本目录对应 Xcode 工程编译安装，资源复制阶段会把修改后的网页带入 App。不要只运行手机上已有的旧安装包。无需先卸载，避免损失本地存档。

本次改的是交付的 Web 构建文件；日后从原始 Cocos 项目重新构建时，需要把相同修复同步到源 SafeAreaAdapter 和 Web 模板，否则可能覆盖修复。

已合并到其他 B 面的静态 SDK 是独立资源副本，不会自动同步；需要重新打包接入。
