# 昵称与多语言更新

更新日期：2026-09-14。适用于本批次 F13、F14、F15、F17、F18、F19、F20、F21（没有 F16 源项目）。

## 使用

- 修改昵称：进入个人账户页，点击昵称右侧的“EDIT / 修改”，或 F21 的独立“修改昵称”按钮，输入 2–18 个字符后保存。游客和本地会员共用此入口。
- 语言：登录页或个人账户页点击 Language / 语言，选择英文、简体中文、繁体中文、日文或韩文。
- 请打开本目录相应项目 DBGame 下的 .xcodeproj，重新运行安装；手机上的旧安装不会自动更新。
- 保持原 Bundle ID 和本地服务端口，不需要卸载旧 App，以免清掉本机数据。

## 范围与限制

通用导航、昵称编辑、登录表单与部分常用提示接入五种语言。主题专属文案、品牌标识、图片内嵌英文和部分法律/规则正文尚未全面本地化，不是全量翻译验收版。原生 Apple / StoreKit 系统弹窗未在本次改动，其语言由系统环境决定。

语言偏好保存在本设备，不是云同步；昵称保存在当前本地账户。更名不会更改账户 ID、购买账户标记或金币余额。卸载后的云恢复不在此次范围。
