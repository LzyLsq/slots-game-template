# F13 Golden Harvest 使用与配置

## 打开与运行

双击 DBGame/GoldenHarvestH5.xcodeproj。工程采用 Objective-C 界面/苹果登录/本地服务器 + Swift StoreKit 2 后端。不是纯 OC，也不是 Cocos 原生渲染；游戏运行于 WKWebView。

- 本地模拟购买：选择 GoldenHarvest-LocalTest 和 iPhone 模拟器，运行。不会真实扣费。
- 沙盒/真机：选择 GoldenHarvest-Release，确认 Edit Scheme → Run 没有关联 StoreKit Configuration。配置签名后测试。
- 发布：配置完成后 Archive；当前交付不是已签名 IPA，也没有上传 App Store。
- 浏览器单独预览：在 F13_H5 目录运行 python3 -m http.server 8765，再打开 http://127.0.0.1:8765。不要双击 index.html。浏览器没有原生苹果登录/内购桥接。

## 苹果登录

工程已含 Sign in with Apple entitlement 与原生 AuthenticationServices 桥接。你需在对应 Apple App ID 开启该能力，并让签名描述文件包含它。真机使用 Apple ID 登录后验证首次登录、再次登录、取消、撤销授权和删除本地账号。

已接入先同意协议再授权，不需要先游客登录。模拟响应测试只检查代码流程，不能证明真实 Apple 账号授权成功。桥接会检查主框架/本地来源与 nonce，身份仅映射至设备本地账号。

## 仍需你配置/确认，不能直接视为上架就绪

1. 每个项目目前沿用 F20 AppIcon 作为构建占位图标；必须换成对应游戏的最终图标。
2. 源码 assets/scripts/core/ReleaseConfig.ts 仍有 REPLACE_WITH_ 发布者、联系信息和网址占位值。检查 LegalContent.ts 及网页 terms/privacy/support，填真实且一致的信息后重构建。默认不注入远程 API。
3. 需要对应 App 的商店名称、隐私与支持链接、截图、年龄分级、素材版权确认。多个近似模板的审核风险需单独评估。
4. 本地账号/金币不做云同步。卸载或清除数据可能丢失；苹果登录并不自动恢复钱包。此版本不提供服务端防篡改、退款后自动扣币或跨设备数据恢复。
5. 删除账号实现的是本机资料删除与同账号再次授权确认；未实现 Apple token 撤销服务。正式上线前需补充评估账号删除/授权撤销方案，不能把本地删除等同于完整云账号注销。
6. WebP 为质量 85 有损编码、alpha 质量 100；修改 Cocos ImageAsset 格式引用后再移除转换成功的打包 PNG。原始项目图片未删除。WebP 缩小下载/包体，不保证纹理解码后的内存按比例下降。
