# Game Design

Astral Vault is the third distinct template in the collection: a 5×3, 20-line Hold & Win game rather than a center-line or cluster-cascade game.

Base results are generated and the wager is debited before reel presentation. Line wins evaluate from the first reel across adjacent reels; Wild substitutes for ordinary symbols, Scatter pays anywhere, and the STAR COIN is feature-only.

Six or more STAR COINS start Hold & Win with their positions locked. Each feature spin evaluates only empty cells. A new coin locks, preserves its value, and resets respins to 3; an empty respin decrements the counter. The feature finishes at zero or at 15 locked cells. Filling the board awards the full-board GRAND.

The Rules screen includes a no-credit-change Feature Demo so reviewers can inspect the full presentation without altering production probabilities. Outcome generation stays separate from animation, and quick stop changes timing only.
