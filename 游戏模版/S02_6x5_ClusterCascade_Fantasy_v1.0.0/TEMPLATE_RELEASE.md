# S02 v1.0.2 Release Notes

## Responsive motion pass

- Adds a true landscape two-column composition while retaining the complete
  portrait layout on narrow phones, and reapplies the layout after resize or
  orientation changes.
- Rebuilds loading as a visible sequence with a rotating magic portal,
  orbiting image coins, progress-bar sweep and changing status copy.
- Removes the redundant static `OPENING THE ARCANE VAULT` preloader before the
  animated loading sequence.
- Recasts `1× / 2× / 3× / 5×` as a clearly labelled, read-only cascade
  progress rail instead of misleading selectable controls.
- Adds drifting arcane particles, board and multiplier-rail light sweeps,
  balance shimmer and lively idle symbol motion.
- Insets the outer rows and columns so ornate frame corners no longer cover
  symbol art, and optically realigns the home and utility icons.
- Extends the drop timing with coordinated top-edge births, gentle rotation,
  squash-and-stretch and a fully settled frame before win evaluation.

## Interaction and economy polish

- Adds persistent multiplier-rune feedback with selected-state art, an energy
  pulse, contextual unlock copy and a physical press response.
- Replaces straight symbol translation with staggered column drops,
  squash-and-stretch landings and subtle cell illumination.
- Removes the guaranteed win on every spin. Outcomes are independent, feature
  clusters are probabilistic, cascade continuations are rarer and payouts are
  rebalanced; a four-loss recovery ceiling keeps the demonstration engaging.
  A 100,000-spin simulation measured approximately 47% hit frequency and 92%
  aggregate RTP for the demonstration profile.
- Bundles Fredoka and Lilita One under the OFL for consistent rounded game
  typography instead of relying on thin platform-default fonts.

## Commercial UI upgrade

- Replaces generic runtime panels and symbol-font controls with a cohesive
  CC API-generated sapphire, purple and antique-gold interface system.
- Adds optically aligned image controls, an animated spin aura, responsive
  spin states, cascade energy progression, image tooltips and touch feedback.
- Rebuilds the win sequence around generated English fantasy wordmarks,
  crystal bursts, a restrained dark stage, 48 image coins and linear balance
  counting.
- Covers wide-screen backgrounds while keeping the complete 6×5 composition
  visible on 390×844, 750×1334 and 1440×900 viewports.

- Introduces the second Slot master-template family: 6×5 Cluster Pays with cascades.
- Adds real connected-component win detection and gravity refill.
- Adds a four-step cascade multiplier.
- Adds an image-led fantasy presentation using licensed Ravenmore and Kenney assets.
- Adds polished portrait loading, rules, recharge and win scenes.
- Adds a dense coin-flow payout effect and linear balance counting.
- Replaces the legacy square-backed special runes with transparent CC API-generated Wild, Scatter and Cascade artwork.
- Resets symbol transforms after every drop so exploded symbols never retain their rotation.
- Adds dark-indigo camera letterboxing for tall phones and wide desktop layouts.
