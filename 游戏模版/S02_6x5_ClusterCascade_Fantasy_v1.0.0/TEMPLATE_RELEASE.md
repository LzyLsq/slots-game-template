# S02 v1.0.0 Release Notes

- Introduces the second Slot master-template family: 6×5 Cluster Pays with cascades.
- Adds real connected-component win detection and gravity refill.
- Adds a four-step cascade multiplier.
- Adds an image-led fantasy presentation using licensed Ravenmore and Kenney assets.
- Adds polished portrait loading, rules, recharge and win scenes.
- Adds a dense coin-flow payout effect and linear balance counting.
- Replaces the legacy square-backed special runes with transparent CC API-generated Wild, Scatter and Cascade artwork.
- Resets symbol transforms after every drop so exploded symbols never retain their rotation.
- Adds dark-indigo camera letterboxing for tall phones and wide desktop layouts.
