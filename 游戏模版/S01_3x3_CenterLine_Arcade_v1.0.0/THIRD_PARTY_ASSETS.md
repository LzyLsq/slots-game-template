# Third-party assets

The candy template uses selected assets from the following Kenney packs:

- Particle Pack: https://kenney.nl/assets/particle-pack
- Game Icons: https://kenney.nl/assets/game-icons
- Fantasy UI Borders: https://kenney.nl/assets/fantasy-ui-borders

All three packs are released under Creative Commons CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

Only the selected PNG files under `assets/resources/theme/candy/vfx/` are
included in this project. Attribution is not required, but the source record is
kept here for production auditing.

The project also contains selected texture-only effects from:

- Cocos Store `Creator3.0粒子特效(23个)` (resource id 3004), saved locally
  through the user's signed-in Cocos Dashboard. Only compatible PNG textures
  are active under `assets/resources/theme/candy/vfx/store-particles/`; the
  original package is retained outside the active `assets` tree because its
  legacy prefabs are not fully compatible with Creator 3.8.8.
- `Cartoon FX Remaster` textures already supplied inside the user's reference
  project at `/Users/xzkj/Desktop/minigame_customize/SlotMachine`. The copied
  alpha textures live under `assets/resources/theme/candy/vfx/reference/` and
  remain subject to the license attached to that original asset package.
