# S10 Sovereign Treasury · v1.0.0

固化日期：`2026-09-03`

## 已锁定能力

- 5×4 转轴、1024 Ways、Cash Coin 倍率与 Collector 收集
- 双 Collector 翻倍收集与可配置奖励权重
- 真实余额、投注扣款、输赢比例和本地持久化
- SPIN、AUTO/STOP、BET ±、SOUND、RULES、HOME、演示充值
- 四阶段转轴运动、逐轴停靠、弹性回弹、中奖符号高亮
- Cash Coin 弧线收集、金币涌入余额、余额线性计数
- 黄金金库机柜、珠宝 Symbol、图片按钮和高级金库结算舞台
- 单一竖屏品牌加载动画，无黑框、绿底或红色闪帧

## 基线验收

- `npm run theme:validate`：必须通过
- Cocos Creator Web Mobile：项目脚本与资源必须构建完成
- 机柜、Symbol 和按钮贴图必须在运行时实际显示
- RULES、充值、SPIN、BET、AUTO/STOP、SOUND 和 HOME 均必须有可见反馈
- 正式截图必须来自真实 390×844 竖屏运行页面
