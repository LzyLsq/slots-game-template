# Paytable

The following values are base multipliers for 3 / 4 / 5 adjacent reels. The award is `total bet × multiplier × winning ways × 0.78`, rounded to whole virtual credits.

- Tidal Pearl: 0.18 / 0.50 / 1.60
- Royal Coral: 0.20 / 0.65 / 2.00
- Spiral Shell: 0.24 / 0.80 / 2.50
- Jade Seahorse: 0.28 / 0.95 / 3.00
- Coral Star: 0.34 / 1.15 / 3.80
- Gold Nautilus: 0.42 / 1.50 / 5.00
- Tide Compass: 0.55 / 2.00 / 7.00
- Royal Trident: 0.75 / 2.80 / 10.00
- Sea Crown: 1.00 / 4.00 / 15.00
- Pearl Throne: 1.40 / 5.50 / 22.00
- Tidal Wild: 1.80 / 7.50 / 30.00

PORTAL SCATTERS pay anywhere: 3 = 1.5× total bet, 4 = 3.9× and 5 = 6.3×. They also award 8 / 12 / 15 free spins. Three or more SCATTERS during the feature add three spins.

Free-spin wins are multiplied by the current persistent TIDE value. The meter begins at 1×, rises after every winning free spin and is capped at 5×.
