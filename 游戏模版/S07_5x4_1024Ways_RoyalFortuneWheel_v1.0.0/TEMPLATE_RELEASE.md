# S07 Royal Fortune Wheel · v1.0.0

固化日期：`2026-09-01`

## 已锁定能力

- 5×4 转轴、1024 Ways 连续相邻匹配
- WILD、Scatter 免费旋转、Coin Tower 收集转盘、Royal Chest Bonus
- 可配置权重、赔率、中奖率、Near Miss 和大奖门槛
- WHEEL POT 增长与持久余额
- SPIN、AUTO/STOP、BET ±、SOUND、RULES、演示充值
- 四行弹性停轮、Ways 高亮、金币雨、金币涌入余额栏和线性计数
- 皇家黄金机柜、珠宝 Symbol、真实图片按钮和透明皇家获奖舞台
- 单一竖屏品牌加载动画，Web 构建去除默认黑底启动屏
- 高对比规则页、充值页和可点击 8 档倍率转盘

## 基线验收

- `npm run theme:validate`：必须通过
- Cocos Creator Web Mobile：必须成功构建
- RULES、充值、SPIN、BET、AUTO/STOP、SOUND、皇家转盘：必须可交互
- 正式截图：必须来自真实 390×844 竖屏运行页面
