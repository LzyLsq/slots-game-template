# F3 WORLD BIBLE — FORTUNE HARBOR

## 统一世界观

Fortune Harbor 是停靠在明亮海港的现代财富邮轮赌场。主持人 Marina Vale 引导玩家在同一座港湾建筑中体验四台真实柜机。整体轻松、喜庆、有博彩气息，但不使用沉重宫殿、黑金夜店或拼贴式 AI 装饰。

统一锚点：太阳罗盘与宝箱徽章、Marina 的象牙色海事制服、香槟黄铜、海玻璃绿珐琅、珊瑚红点缀、胡桃木、厚玻璃、钱币压纹和清晰无衬线功能文字。图片不烘焙功能文案；标题、金额和按钮标签由 Cocos 渲染。

## 柜机基准

- Game 01：S05 的完整高占屏几何比例 + S06 的金属材质完成度。
- Game 02：S06 的大屏与机械精度 + S07 的舒展控制台。
- Game 03：S07 的实体下方特色轮盘 + S05 的明亮环境感。
- Game 04：S08 的六轴宽屏空间 + S06 的精密金属细节。
- 每台均保留五个独立实体控制位：左侧 Bet − / Bet +、中央大 SPIN、右侧 AUTO / TURBO。
- 禁止转轴越界、屏幕贴纸感、按钮堆叠、纯黑矩形阴影和无功能装饰按钮。

## 动效与可读性

- 竖屏优先，390×844 至平板尺寸保持屏幕完整可见。
- 转轴使用预压、加速、恒速、减速、对齐、`backOut` 回弹六段节奏；逐轴停靠 80–120ms。
- 所有按钮具备压缩、图标放大、粒子回馈与音效/震动钩子。
- 赢分按 impact、连线/簇高亮、金额计数、金币流、分级覆盖、退出顺序演出。
- 最小功能文字等效不低于 16px；金额、CTA 与关键状态等效不低于 20px。
