# F40 本轮优化与验收 — 2026-10-12

预览版本：`f40-polish-20261012`。本轮保留 F40 的原创节庆美术、四模式规则及余额流程，集中解决切换生硬、数值不清楚、辅助页拥挤和短屏裁切。

## 实际改动

- **大厅**：入口插画、艺术标题和规则提示作为同一组淡入淡出。重复点击当前入口不重建画面和动画；快速切换后仅保留最终入口。选中光泽同步平滑过渡，减少闪换与残留。四个入口使用各自已有原创主题符号。
- **柜机**：重新设置 COINS / BET / WIN 的字号、基线和框内宽度，把充值入口移到不遮数字的位置。工具栏收回安全区。短屏适配计入角色父图层偏移、动作余量及头顶留白，保留角色头顶、柜机底座和转轴开口。
- **按钮**：修正统一按压逻辑中强制压缩至 94% 的限制，使已设置的轻按压生效。大厅、导航和商店按各自参数柔和回位。
- **商店与奖励**：调整金币、加赠、价格和状态的间距；宝箱商品匹配原有宝箱图标。签到金额与已领取标记分开排列。
- **排行与账户**：扩大排行行距并匹配头像尺寸；排名、名字和金额各在自己的区域内。账户统计、说明和记录按钮重新分配空间，避免数字与标题拥挤。

## 本轮验证

- TypeScript 类型检查、40 组柜机/屏幕几何检查、多语言、排行及获奖层级测试通过。
- 大厅及四台柜机更新了 390×844、320×568 两种尺寸截图；短屏四台柜机逐张检查头顶、底座、转轴与数值。
- 六个辅助页覆盖两种手机比例，四个模式均截取真实加载过程。加载截图通过 QA 延迟本项目资源请求 1 秒取得；正式游戏未增加这段延迟。
- 15 项实际运行检查通过：连续双向选择与快速切换、四模式入场/扣注/旋转/结算/返回、AUTO 开关、奖励防重领、账户切换、五种语言、声音生命周期、加载失败返回/重试及无滚动、无浏览器错误。

最终几何调整只改变柜机适配；此前服务页和交互检查仍适用于未改动的功能。后续的转轴裁切与连续录制使用最终构建单独复核，结果见下方。

## 最终构建专项复核

- 最终构建的 20 组柜机/语言检查通过，所有活动文字框位于短屏视口内，无整页滚动或浏览器错误。
- 四台柜机 × 两种手机比例共 8 组 GPU 遮罩检查通过：临时放入三倍尺寸的探针，所有可见像素均保留在转轴玻璃开口内，开口外探针像素为 0。
- 四模式各录制一段约 10 秒待机及一段实际扣注、结算的调试 SUPER 过程，共 8 段。顺序解码原始时间戳，并复核每台角色的 16 个原始姿态及代表演出画面；抽查姿态未见双层轮廓，头顶及身体接触位置保持完整。角色使用单一图像来源的局部关节网格，父节点位置、角度与缩放固定，不用整张图片放大缩小实现动作。
- 四模式均记录到眨眼与局部招财动作。每段待机采样 99 次；每轮扣注和结算各一笔，余额守恒，演出后恢复操作。调试 SUPER 检查的是演出与已结算轮次的衔接，不代表自然中奖率。
- 大厅实际画布连续录制覆盖四次触摸选区；转场结束每次只留下当前选中入口，插画、标题和规则一同过渡，没有残留的旧入口或浏览器错误。
- 原始录制时间戳并非均匀：大厅最长帧间隔 77 ms，麒麟旋转/演出录制曾出现 601 ms 间隔。因此追加两次独立旋转/演出检查，用 requestAnimationFrame 测量页面帧间隔：关闭录制时最大 16.8 ms，开启录制时最大 33.3 ms，两次均无超过 100 ms 的间隔、无 Long Task 或浏览器错误，未复现较长停顿。原始 601 ms 间隔原因尚未确定；桌面采样不能证明手机实机帧率或所有运行条件下全程丝滑。
