# F40 图集裁剪与暗边修正 · 2026-10-12

本轮针对图集邻格残片、冠饰/流苏被截断及文字衬底的硬暗边。保持原有庆典场景、已修正吉祥物及上一轮大奖演出。

## 修改

- 从已委托生成的原始 RGBA 识别完整独立物体，以连通轮廓分配边缘和分离的小装饰，再按原语义序号放回图集。处理 64 个转轴符号、16 个界面图标、16 个控制按钮、4 个入口，以及边框、提示板、中奖框和奖级艺术标题。
- 每个元素等比例装入自己的格子并留透明边距；转轴与入口/光学图集采用分别定义的裁切表，避免混用行列规格。
- 透明边缘扩展相邻的原画 RGB，纹理使用 clamp-to-edge，保留资源 UUID。运动模糊按单格、预乘透明度处理，避免黑边与相邻物体污染。
- 柜机状态文字和大奖金额衬底改为单层、横纵方向柔化的主题色遮光，消除旧全宽条带的硬端点和叠加底板的过暗部分。
- 增加 `art-source/prepare_atlases.py`。完整素材准备流程保留已安装的房间延伸与吉祥物修正；生成流程在源图就绪后重新提取完整物体。
