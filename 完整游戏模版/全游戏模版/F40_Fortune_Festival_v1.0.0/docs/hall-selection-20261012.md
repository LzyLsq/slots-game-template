# F40 大厅选中效果修正 · 2026-10-12

预览版本：`f40-gilded-selection-20261012`，端口 `6040`。

## 修改

- 四个模式入口选中后显示雕花金色底座、暖金文字和局部金属反光。扫光通过入口图案的透明轮廓遮罩裁剪，避免出现矩形光片。
- 底座取自本工程已有建筑边饰，保持图片比例；没有新增异风格图标，也不缩放或扭曲入口图片。
- 选中与取消采用 0.22 秒有界渐变；快速反向切换时从当前状态继续过渡。扫光在 1.45 秒内经过图案，每 5.4 秒循环一次。
- 底部商店、奖励、大厅、排行、账户导航移除选中的深色圆形底和描边，使用同材质雕花底座与小范围金色反光。
- 减少动态模式保留静态选中标记；未选中的光效退出至透明，非活动组件停止待机更新。

修改位于 `assets/scripts/vfx/HallSelectionAccent.ts`、`assets/scripts/ui/SalonArt.ts` 和 `assets/scripts/ui/AureliaApp.ts`。原有入口点击范围、滑动切换、标题与场景过渡继续使用。本轮未修改音乐、获奖演出、结算或概率。
