# F40 演出与音乐打磨 · 2026-10-12

当前预览版本：`f40-award-music-polish-20261012`，本地端口 `6040`。

本轮围绕现有柜机的演出节奏与音乐配合完善，没有修改结算、下注、奖级门槛或自然中奖概率。原有柜机、角色、中奖结果和操作台始终留在场景中。

## 本轮修改

- 金额揭晓后的两次高潮共用时间标记：第 0.20 秒和第 1.05 秒。柜机反光、标题金属扫光、后景礼花和第二波金币与两次音乐重音对应。数钱、奖级升级和最终揭晓各有节奏，提前揭晓也走同一套收束。
- 最终揭晓不再叠加一次额外的奖级音效与礼花。金币流和场景光照在揭晓后逐渐减弱；退出时，文字、地面阅读衬底、光效和演出音乐同步淡出，再恢复背景音乐与原操作台。
- 领取开始只播放一次当前柜机调性的到账短句，保持原金币飞向 COINS 的表现。该音效与演出不发放金币：钱包在演出前已经完成真实结算，演出结束后刷新可见余额。
- 重排并重新渲染全部 90 段音频：降低铜管音区，收敛主旋律力度，加入与主题调性对应的拨弦应答，重写双重音的揭晓乐句及下行收尾。数钱与揭晓的运行时音量也有所降低，减少同时播放时的拥挤。
- 母带保留柔和的高频处理，并加强到高架滤波 −4.2 dB、存在感频段 −2 dB。文件级信号检查无削波。滤波参数不能证明所有片段的高频能量都下降，也不能代替耳机与手机扬声器试听。
- 四台柜机的底部提示增加与各自地板色调对应的双轴渐隐衬底，麒麟明亮地面使用稍强对比。材质随提示一起进入、随尺寸重新布局、随演出退出，未增加黑色矩形条。

## 帧时间与导出限制

第一次四柜机录制中，龙柜机出现一次 116.6 ms 的 RAF 间隔，原视频对应最大间隔 154 ms。随后对龙柜机在不录制、不截图的条件下连续检查三轮，各轮最大 RAF 间隔约 16.8 ms，未捕获长任务或超过 100 ms 的间隔。该复查不抹去录制中已观察到的间隔，也不代表 iPhone/iPad 性能验收。最后麒麟录制最大 RAF 间隔约 16.8 ms，386 个顺序解码原视频帧的最大间隔 51 ms，未出现超过 100 ms 的间隔；原始测量保存在下方证据中。

最后 Cocos Creator 3.8.8 导出日志报告 `Finished`，导出用时约 9 秒，但命令退出码为 **36**，日志包含构建脚本 worker 的 **SIGTERM**。当前导出运行、源码更新以及全部 90 段音频哈希已验证；这里不能记为干净的 CLI 成功退出。两次日志均保留，发布前仍需消除该诊断并做正式构建验证。

未做耳机、手机扬声器主观试听或移动原生包验证。因此不能将本地检查称为最终听感、实机性能或商业发布验收通过。音频是原创 MIDI 编排通过 FluidSynth / GeneralUser GS 采样库渲染，不是成品游戏录音；素材来源与许可披露继续见 [音频来源记录](sampled-audio-20261012.md#sources-and-reproducibility) 和 [最终母带清单](audio-provenance.json)。
