# F40 获奖演出加强 · 2026-10-12

当前预览版本：`f40-award-crescendo-20261012`。本轮针对“演出动画平平无奇”的反馈，强化四台柜机的演出节奏、画面重心及原场景中的庆祝反馈。沿用 F40 自有图像和可靠结算流程，不新增跨项目图片。

## 本轮变化

- 获奖艺术标题从约 230×145 扩大到约 520×250 的柜机局部尺寸，展开位置跨柜机铭牌与上部玻璃。原模式标题在演出期间淡出，退出后恢复；图像保持原始比例。
- 金额从小额起逐步累加，达到本次实际下注的 10×、50×、100× 时，依次进入 SUPER、MEGA、EPIC。BIG、SUPER、MEGA、EPIC 仍沿用现有结算分级；提前揭晓直接进入最终等级。
- 金额字体提高到局部字号 108，独立于标题缩放。金额与说明使用整数位移，避免文字随装饰持续缩放。
- 金币使用已有高质量金币图片，从柜机财宝台向两侧形成较宽的抛物线喷泉。最终揭晓增加两轮错峰喷发；文字、金额、金币表和操作区保留独立避让带。
- 柜机皇冠、财宝台和金属边饰增加随累加及揭晓变化的暖色反光，标题扫光与金额、金币喷发错开节奏。
- 吉祥物在升级、揭晓时触发局部肩部和腕部庆祝动作，继续保留眨眼与固定接触点。整个人物的位置、缩放和角度保持固定。
- 结束时 9–18 枚金币飞向真实 COINS 表位置，喷泉继续运动并渐隐，原标题与 SPIN 文案恢复。演出方法不修改钱包，到账仍由原结算流程负责。

普通奖保留原有反馈；本轮加强 BIG 及以上演出，没有改动自然概率、奖励金额、下注扣款或新手福利规则。演出始终在当前柜机和房间中进行。

## 录制时序与实际限制

最初录像曾出现较长采集间隔，因此额外对凤凰与玉龙 EPIC 顺序录制，避免同时进行重解码。完整时序存于 `isolated-motion/direct-canvas-audit.json` 和 `sequential-decoding.json`。

| 隔离录制指标 | 凤凰 EPIC | 玉龙 EPIC |
|---|---:|---:|
| 页面 rAF p95 间隔 | 16.8 ms | 16.7 ms |
| 页面 rAF 最大间隔 | 99.9 ms | 50.1 ms |
| 页面 rAF >100 ms 间隔数 | 0 | 0 |
| Long Tasks | 83 ms、104 ms | 无 |
| 原视频最大帧间隔 | 157 ms | 98 ms |
| 原视频 >100 ms 间隔数 | 3 | 0 |
| 观察到的升级路径 | BIG → SUPER → MEGA → EPIC | BIG → SUPER → MEGA → EPIC |

凤凰录制轮次入账 12,000，最终余额 38,920。玉龙轮次同时触发正常特色玩法，实际总入账 **13,324**、余额 **40,244**，录像长约 34.5 秒。

隔离复测没有复现此前较长页面停顿，但凤凰录制仍有少量较长源帧间隔及 Long Tasks，不能声称所有卡顿均来自采集，更不能用桌面录制证明手机全程流畅。iPhone/iPad 实机性能、听感、原生服务、签名与发布验证沿用项目现有待验收状态。
