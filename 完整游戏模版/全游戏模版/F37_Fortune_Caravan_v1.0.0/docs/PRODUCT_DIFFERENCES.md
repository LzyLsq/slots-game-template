# F37 与 F35 的实质区别

比较对象：本项目 F37 Fortune Caravan 与交付版 F35 Sovereign Mint。以下是实现差异，不是 App Review 认证。

| 维度 | F35 | F37 |
|---|---|---|
| 基础 3×3 | 7 线 + 逐步增长的 WILD 特色 | 5 线 + 2 次免费逐轴 travelling-WILD 重转 |
| 5×3 Ways | 命中格变 WILD，结算增量 | 243 Ways + 4 次 sticky-WILD 免费旋转 |
| 第三模式 | 每轴 2–4 行，免费下落 | 固定 5×3/25 线，4 次 mystery 揭晓免费旋转 |
| 第四模式 | 8+ 全盘计数 | 5+ 横纵连簇、邻格清除、3 次倍数下落 |
| 大厅导航 | 四个金库入口 | 原地选择旅程地区、对应财富展示与吉祥物、直接 PLAY |
| 独立成长 | 原有日常奖励 | 跨地区访问及已结算回合共同推动四个旅程站，独立交易类型 |
| 原创画面 | 铸币/金库 | 商队拱廊、绿洲、红宝石集市、财富港口；重新生成柜机、角色、按钮、标题与奖励画面 |
| 角色 | 狮/麒麟/海马/凤凰 | 狮/象/孔雀/鹦鹉，柜机原画预留壁龛、局部招财动作 |
| 音乐 | 旧金库编曲 | 独立场景旋律/和声/拍号/角色乐器，保留分级结算与压背景机制 |

保留的基础设施：Cocos、账户与存档隔离、钱包/交易幂等、Apple/IAP 接口合约、可复用文本适配与转轴/音频调度。四个模式属于一个完整产品的不同玩法，不能仅将四模式各改 bundle ID 就视作四个独立可上架产品。

还需发行方完成产品定位与实机审查，包括与其他已上架产品的差异、目标用户、元数据、授权和实际后端；因此独立提交状态没有被自动置为通过。
