# F37 · Fortune Caravan（财富商队）

Cocos Creator 3.8.8 完整**虚拟金币 Slots 游戏模板**。原创商队、绿洲、珠宝集市与皇家港口主题；不是将 F35 的四套规则改名换图。无现金奖励、提现或真实货币赌博。

## 四套真实 Slots 玩法

| 模式 | 基础规则 | 免费特色回合 |
|---|---|---|
| Caravan Gold | 3×3，5 条始终启用的左起赔付线 | 首轴出现 WILD 触发 2 次免费重转，WILD 逐轴旅行；每张新盘仅结算一次 |
| Sapphire Oasis | 5×3，243 Ways | 3+ SCATTER 触发 4 次免费旋转，WILD 留在原格；不重触发 |
| Ruby Bazaar | 5×3，25 条赔付线 | 3+ SCATTER 触发 4 次 Mystery 免费旋转，只结算揭晓后的最终盘 |
| Crown Voyage | 5×5，5+ 横纵相邻连簇 | 中奖格及其横纵邻格清除，最多 3 次下落，依次 1×/2×/3×；对角不连通 |

下注档位：30、80、180、400、500、900。扣注、结算、取消恢复和重复请求有独立测试。免费回合不追加下注，整局上限包含基础及特色奖励。

### 商队旅程：跨模式的独立成长系统

完成已结算回合并探索不同地区解锁四个旅程站：5 回合/1 地区 → 800；12/2 → 1,600；24/3 → 3,000；40/4 → 6,000。奖励独立记账、账号隔离、幂等领取，不改变转轴概率。远程模式默认禁用本地旅程发币，须接入服务端权威接口。

### 中奖演出与新人权益

- 0 < 返还 ≤ 下注：普通奖/部分返还/下注返还，有清楚的金币数值与独立音效。
- 返还 > 下注：大奖；≥10× 超级大奖，≥50×/100× 保留更高演出等级。
- 新人第 5 个已结算回合不足 10× 时，补足至 10×。界面公开提示，这是**虚拟金币新人补足**，交易类型为 `newcomer-benefit`，不伪装成自然中奖，不改自然盘面，也不计入自然 RTP 模拟。
- `force`、`showcase` 只在 localhost 且 `debug=1` 生效，不能在正常线上会话强制中奖。

## 完整界面与原创资产

登录/注册/游客入口、加载、大厅、四柜机、商店、旅程奖励、排行、账户、设置及分页面规则。
大厅在原地滑动切换地区，PLAY 直接进入对应柜机，不加独立模式选择中间页。

11 张原创生成源图在 `art-source/`，处理脚本 `tools/prepare-caravan-art.py` 保留透明裁剪与图集间隔。柜机原图约 836×1881，处理为 1024×2304；原始图集约 1254×1254，标题图 1024×1536。**放大不是新增细节，不宣称 4K 原画。** 一个原创财富符号图集按规则选用不同符号，四套模式共享纹理以节省解码及显存。

四个独立吉祥物：狮子、大象、孔雀、鹦鹉，固定于柜机对应建筑壁龛，手/翅膀局部招财动作、轻呼吸与触摸反馈；减少动态偏好下静止。使用原图纹理按钮，不用 CSS 小图标代替主体美术。标题位图有柔和动态；余额/下注/赢币等关键数值使用清晰实时文字。

大厅与柜机均有有限池的金币/反光/环境细节；切换不黑屏。转轴及效果受柜机玻璃区域遮罩限制。自定义吉祥物网格通过引擎索引扩容路径提交，避免共享缓冲溢出导致大厅冻结。

## 音乐与反馈

59 个独立 AAC：5 首场景背景曲、40 个分级获奖/收尾段、14 个功能音效。大厅、沙漠、绿洲、集市、港口是不同编曲及旋律，不是同曲改速度。点击、下注、切换、旋转、停轴、普通返还、大奖、收金币分别反馈；场景交叉淡入淡出、中奖压低背景、隐藏页暂停。BGM 与音效开关独立保存。

原创 MIDI 编曲用本机 CoreAudio 采样乐器离线渲染，不是现场乐队录音；不打包系统音色库。`docs/qa/audio-technical.json` 检查实际文件解码、峰值、循环接缝、按钮起音及高频能量。**技术检查不能替代音箱/耳机试听、素材授权审核或 iPhone 真机验收。**

## 安装、构建与运行

```sh
npm ci
# 第一次用 Cocos Creator 3.8.8 打开本目录，生成 temp/tsconfig.cocos.json。
npm run typecheck
npm run typecheck:server
npm test
/Applications/CocosCreator.app/Contents/MacOS/CocosCreator --project "$PWD" --build "configPath=$PWD/tools/web-mobile-release-build.json"
python3 tools/preview_server.py --directory build/web-mobile --port 6037
```

访问 `http://127.0.0.1:6037/`。本地调试入口：
- 大厅：`?debug=1&screen=home`
- 柜机：`?debug=1&screen=game&game=caravan-gold`
- 演出：以上柜机 URL 加 `&force=big&autospin=0&showcase=1` 后点击 SPIN；支持 `ordinary`/`big`/`super`。showcase 保留真实结算演出以便截图，点击收取退出；普通奖点击金额条退出。

本机 CLI 在日志 `Finished`、产物完整时返回 36；因此同时检查日志与实际浏览器，不能仅将该退出码解释成成功或失败。缓存、node_modules、build 与临时生成请求不进入 Git。
