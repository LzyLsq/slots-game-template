# FORTUNE BLOOM CARNIVAL F6 — 屏幕适配报告

验证日期：2026-09-08
运行环境：Cocos Creator 3.8.8 Web Mobile Release / Chromium

## 适配策略

- 设计分辨率为 1080×1920，`SafeAreaAdapter` 根据视口比例选择固定宽度或固定高度。
- 背景使用 Cover 等比铺满；实体柜机、转轴、控制台和光效共用同一柜机缩放系数，不单独拉伸部件。
- 顶栏、右上工具键和底部 Fortune Dock 读取安全区边距；横屏由独立旋转提示覆盖。
- 四台柜机使用独立测量参数，分别定位标题、TOP WIN、余额、WIN、BET、转轴和按钮插槽。
- 转轴使用与物理镜片一致的圆角遮罩，弹跳、急停和中奖放大均不会越出金属框。
- 交互热区跟随按钮尺寸缩放，并保持在可见安全区内。

## 视觉与动态层次

- Golden Parade、Blossom Fortune、Lantern Treasure、Treasure Wheel 分别采用金币输送机、牡丹温室、灯笼锁币机和实体转盘机结构，不是同一机身换皮。
- 四套控制图集使用不同轮廓与材质；按钮图片扩大后嵌入真实插槽，SPIN、加减、AUTO、TURBO 与工具键不再缩成小图标。
- 转轴镜片扫光、边缘跑灯、标题呼吸、SPIN 双环、环境漂浮物和符号弹性在待机状态持续运行。
- 大厅、登录、商店、奖励、排行和账户使用对应的花园、宝库、牡丹与庆典图片场景，避免大面积廉价纯色。
- 本轮未观察到转轴越界、标题压住 TOP WIN、按钮堆叠、卡片覆盖或装饰裁切文字。

## 真机补充项

桌面 Chromium 无法完整模拟所有灵动岛、系统手势条、Dynamic Type 和系统音频中断。iOS 原生封装完成后，仍需在最低支持版本的实体 iPhone、当前主流 iPhone 与最大尺寸 iPhone 上复核安全区、StoreKit、Sign in with Apple、触感及音频恢复。
