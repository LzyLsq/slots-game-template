# F6 数学设计

## 公平与可控边界

- `RandomSource` 可注入；生产使用安全随机源，固定种子仅用于测试。
- 每次 Spin 在动画开始前生成并冻结；下注只接受配置白名单值。
- 钱包先预扣再幂等结算；路由中断或异常会释放未结算下注。
- 每款声明目标 RTP、波动等级和最大赢分倍数，结算层执行硬上限。
- 强制结果仅在 localhost 且显式 `debug=1` 时可用。
