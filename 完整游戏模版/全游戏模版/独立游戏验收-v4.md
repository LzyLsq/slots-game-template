# F13–F23 独立游戏 v4 验收记录

日期：2026-09-16。**当前为可运行的 Web 验收版本，不是已完成 App Store 上架验收的成品。**

实际找到10个项目、40个柜机；F16源码未找到。本表覆盖当前v4实现，旧版玩法记录不应作为现行规则依据。

## 实际结算差异

|项目|基础机制|四柜机区别／关键约束|
|---|---|---|
|F13|固定中奖线|3/4/5/5列；5/10/20/25条线|
|F14|可变格数 Ways|每转各列独立开放2至4/5格；封闭格不参与结算|
|F15|连块消除|5/6/7/8个四向相邻符号成组；下落／上升消除|
|F17|逐列路径连接|相邻行／仅对角／仅下行／仅上行路径|
|F18|纵向中奖线|向下／向上／双向择优／曲折纵向|
|F19|收集者盘面|全盘／同行／同列／四邻收集；重复覆盖只付一次|
|F20|任意起列 Ways|5/6/6/7列；任意列起算，最大连续段只结算一次|
|F21|独立双盘|两个独立3行盘面，各用一半总注；符号不跨盘下落|
|F22|全盘同符号计数|6/7/8/9个起付；Wild单独计数，不替代|
|F23|扑克牌型转轴|1/2/3/4手；每手只付最佳牌型，全轮合并取整|

十款使用不同主结算机制；同款四柜机共享其主机制并有盘面、方向、阈值和特色回合的变体。不能表述为40套互不相关的主机制。

## 已执行验证及其边界

- 10款客户端、服务端类型检查和Web构建；数学、规则、账户及交互测试。新增主机制回归已纳入npm test。
- 浏览器构建与源码相同随机种子的结果比对：每柜机3,000轮，40柜机共120,000轮。
- 40柜机特色回合动画终态、扣注和派奖；这些测试不代表真机稳定60fps。
- 每款120项柜机文字检查、80项常规页面检查，覆盖英文、简繁中文、日文、韩文以及窄屏。未报告测量溢出；不等同于所有设备、所有金额和视觉遮挡都无问题。
- 保存40张414×896柜机截图；这是浏览器尺寸模拟，不是真实iPhone截图。
- F14修复封闭格参与上升/移动动画的问题；F21加强双盘分隔；F23修复小额奖励逐手取整，整轮结算一次；F19收集金币保留小数余量，F20连消和倍数奖励整轮统一分配整数金币。

## 仍未完成，不能宣称可提交成品

1. 原生StoreKit 2和Sign in with Apple桥接尚未实现；当前协议文件不能替代可执行的原生接入。
2. 尚无Sandbox购买/退款/重试、TestFlight、真实iPhone五语验证记录。
3. 需真实发行方、Apple Team、各款Bundle ID、内购商品、生产API、数据库和法律/支持页面配置。
4. 部分导航和柜机控制布局仍相似，需要继续完成逐款视觉与交互验收。不同结算不自动证明产品足够独立。
5. 经济验证仍是开发阶段抽样，不是认证RTP。F19/F20已修复明显的低注取整偏差；F18完成75万轮训练样本校准和50万轮独立样本复核。后续修改数学参数仍须重新验证。
6. F16不在当前源码中。

各项目docs/independent-v4-release-status.json均明确readyForSubmission=false。任何上架结果须经实际审核，当前不作通过承诺。
