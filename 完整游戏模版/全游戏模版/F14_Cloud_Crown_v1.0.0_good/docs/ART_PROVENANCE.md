# F14 original artwork

Cloud Crown is a soft cartoon treasure regatta. F5, F6, F8, F12 and F13 were reviewed for material quality and composition. Login, route lobby, cargo shop, seven-port rewards, honours and passport use new compositions.

Generated with the previously authorized CC Switch workflow (gpt-image-2): login environment, cloud port, four complete cabinet scenes, four vehicles, 16 symbols, 16 adult crew portraits, 16 interface icons, 16 themed controls, four enamel panels, four service environments, logo and celebration airship. Exact prompts are in art-prompts/.

Sprites are individually cropped and keyed from magenta backgrounds. Cabinets are normalized from 887x1774 to a single 1536x3072 scene. Measured reel apertures and controls share the same transform. The rotating admiral compass is extracted from its own scene.

Reused: validated Cocos services/math, audio, standard Apple mark and optical textures from F13/F8. F14 has an independent project UUID and save namespace. Internal math identifiers stay compatible; no F13 cabinet or lobby wall artwork is used. Production Apple sign-in, StoreKit and distribution require publisher configuration and native validation.
