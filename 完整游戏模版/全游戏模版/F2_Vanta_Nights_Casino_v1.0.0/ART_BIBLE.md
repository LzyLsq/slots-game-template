# F2 WORLD BIBLE — VANTA NIGHTS

## 统一世界观

Vanta Nights 是一座永不熄灯的未来夜都会赌场。主持人 Ava 带玩家穿过四个相连的娱乐厅。整体不是庄重宫殿，也不是厚重黑金：观感应当轻奢、热闹、带社交夜生活气息，像成熟商业赌场 App 的旗舰楼层。

统一锚点：日蚀钻石徽标、Ava 的银黑荷官制服、圆角切面黑曜玻璃、香槟铬边、细窄霓虹线、筹码形圆形控件、清晰无衬线艺术标题。生成图片不烘焙文字，Logo 文字由 Cocos 清晰渲染。

## 主持角色 Ava

- 25–35 岁的原创未来派荷官，友好、自信、动作轻快，不做严肃君主姿态。
- 银黑短夹克、日蚀钻石胸针、主题色耳饰；脸型、发型和服装轮廓四模式一致。
- 四张模式图只改变手持道具、环境反光和姿势，不改变身份。

## 构图与可读性

- 竖屏 9:16，390×844 到平板宽度均保留安全区。
- 大厅卡片主视觉不压标题；游戏屏幕占主体，控件不与转轴争夺面积。
- 文字不烘焙进生成图，最小功能文案等效 16px，金额和主要 CTA 等效 20px 以上。
- 禁止纯黑投影框、发灰蒙层、随机贴纸式图标、悬空无承托按钮和与主题无关装饰。
- 高光应克制：亮点服务于层级，不用整屏闪白。

## 动效节奏

- 页面：180–360ms，轻微位移 + 透明度，不用僵硬缩放。
- 转轴：加速 → 恒速 → 逐轴减速 → `backOut` 回弹；Turbo 只缩短时间。
- 赢分：impact → reveal → 金额线性 count-up → tier overlay → 金币/筹码流向金额条 → exit。
- `prefers-reduced-motion` 或低画质时减少粒子数量、取消持续漂浮，不影响结果与按钮反馈。
