# LUCKY SKYLIGHT CASINO F5 — 屏幕适配报告

验证日期：2026-09-07
运行环境：Cocos Creator 3.8.8 Web Mobile Release / Chromium

## 适配策略

- 设计分辨率为 1080×1920，`SafeAreaAdapter` 根据视口比例选择固定宽度或固定高度。
- 背景使用 Cover 等比铺满；柜机主体与按钮共用同一设计坐标，不对单独部件做非等比拉伸。
- 顶栏、右上工具键和底部星轨 Dock 均读取安全区边距。
- 横屏由独立旋转提示覆盖，避免在不适合的比例下暴露可玩控件。
- 游戏标题、TOP WIN、余额、WIN、BET 和五组操作键针对四台柜机分别校准，不共享一套机械坐标。

## 视觉层次检查

- 大厅以玻璃穹顶财富星轨为统一世界观，四个入口沿轨道交错，不使用常规模板式大卡＋三小卡布局。
- 移动端底部空场增加 Live Fortune Floor 状态舱，并以两个运行光点串联四个游戏节点。
- 四台柜机均保留摄影级实体轮廓、主题专属按钮图集、镜面反光、边缘跑灯、SPIN 光环和待机微动。
- 奖励演出使用四套不同机械舞台纹理和路径动画，不共用单张纯色结算卡。
- 390×844 下未观察到转轴越界、标题压住 TOP WIN、按钮堆叠或文字被装饰裁切。

## 真机补充项

桌面 Chromium 无法完整模拟所有刘海、灵动岛和系统手势条。iOS 原生封装完成后，仍应在目标 iPhone 机型上复核安全区、系统字体缩放、触感和音频中断恢复。
