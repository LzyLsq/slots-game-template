# F5 WORLD BIBLE — LUCKY SKYLIGHT

## 统一世界观

Lucky Skylight 是一座夕阳照入玻璃穹顶的现代财富赌场。视觉关键词是香槟金、奶油白、天青、杏桃和少量深酒红；材质限定为拉丝黄铜、奶油皮革、磨砂玻璃与精细珐琅。品牌锚点是太阳钻石徽章、主持人 Elodie 和“财富星轨”——金币、筹码、骰子沿黄铜椭圆轨道运转。

整体要奢华但轻松，避免红黑夜店、传统宫殿、国风庆典、空洞科幻 HUD、静态柜机贴图和互不相干的拼接背景。

## 产品规则

- 四台柜机体量和工艺达到 S05/S06 基准，但轮廓、材质、按钮必须分别适配主题。
- 上方余额槽显示“金币图标＋数字＋充值按钮”；TOP WIN 在艺术标题下方；WIN 居中，BET 跟随加减键。
- 按钮不能堆叠，每个按钮有清晰图标、按压、灯态、音效和震动钩子。
- 标题、金额、CTA 使用粗体、高对比和描边；390×844 下不得被装饰或信封遮挡。
- 待机至少同时存在环境光尘、柜机边缘灯、财富星轨、镜片反光和特殊符号呼吸，避免整页像一张静态图。
