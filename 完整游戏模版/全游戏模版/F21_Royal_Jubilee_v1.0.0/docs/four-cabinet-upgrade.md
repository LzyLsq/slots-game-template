2026-09-16。仅 F21 已完成本轮四柜机差异化；不是 F13–F23 全量完成报告。

|柜机|基础结算|真实盘面变化|
|---|---|---|
|SUN CROWN|3×3 中央单线|含 WILD 的列整列扩展，仅补发扩展后的正差额|

## 已完成验证

- 全套 npm test、客户端和服务端类型检查通过。
- 24,000 次自然生成测试，包含触发条件、回合停止、守恒与限额检查。
- 800,000 次独立抽样调参验证；仅为原型抽样，不是认证回报率。
- 12,000 次相同种子源码／Cocos 网页结果逐项一致，覆盖所有四种特色机制。
- 浏览器逐柜机播放特色动画，检查最终盘面与实际扣注／派奖；见 screenshots/four-modes/qa.json。
- 320×568、414×896 截图检查四柜机、大厅、账户、商店、奖励、排行。
- 另外九款各 12,000 次源码／网页结果对比通过，36 个柜机验证本次兼容性修复；这不代表它们的玩法差异化改造完成。
- 修正 Set 展开在网页构建后变成错误索引的问题；同类中奖标记问题同步修正到另外九个模板，以及 F13 的重播种选列。
