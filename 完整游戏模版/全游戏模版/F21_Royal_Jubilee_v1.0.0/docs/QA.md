# F21 验证记录

日期：2026-09-14。环境：Cocos Creator 3.8.8 Web Mobile；本机 Chrome headless 浏览器。不是 iPhone 真机验收。

## 自动检查

- TypeScript 客户端和服务端检查通过。
- npm test 全部通过：4,000次数学模拟、Apple授权契约、排名、32种布局尺寸、630组规则数字、五种语言及英语默认值。
- 最终 Web Mobile 构建成功。
- 20个最终页面/尺寸截图：390×844全部页面与四柜机，320×568登录/注册/大厅/商店/奖励/排行/账户，768×1024两柜机；页面脚本错误为0。
- 四入口实际点击、模式加载、加减投注、规则、音效、返回、注销/登录/注册通过。
- 签到与每日宝箱重复操作仅到账一次；头像保存后刷新保留。
- 四档商品和恢复购买在浏览器中均不伪造付款成功、不额外发币。
- 四柜机起转保持原始符号连续；速度变化有界；停轴结果与目标网格一致；落轴回弹接待机无跳变。

- 四柜机普通中奖、大奖独立演出通过。大奖检查使用调试调用，确认主题标题、关闭清理及钱包不重复入账；不作为中奖概率统计。
