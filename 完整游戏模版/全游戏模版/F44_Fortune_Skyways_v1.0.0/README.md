# F44 · Fortune Skyways

Cocos Creator **3.8.8** 完整游戏模板。明亮云海中的香槟金空港、财宝飞艇与四位卡通船长；游戏插画经授权的本机 CC Switch 服务新生成。F40 的结算、账户和可靠基础代码作为功能起点，F44 改变场景、四模式规则、入口结构、成长目标及视听内容。

## 当前运行

本地 Cocos 预览：**http://127.0.0.1:6044/**。此地址运行 Creator 的 web-mobile 导出，用于制作与审查；工程使用 Cocos 节点、转轴遮罩、关节网格与音频系统。

打开 `assets/scenes/FortuneSkyways.scene`，使用 Creator 3.8.8 编辑或导出。恢复本地预览：

```sh
npm install
python3 tools/preview_server.py --directory build/web-grand-prize-20261013 --port 6044
```

本轮预览使用独立目录 `build/web-grand-prize-20261013`，避免与并行的 Xcode 构建覆盖。普通重新导出仍可使用 `build/web-mobile` 并相应更改 `--directory`。从 Creator 导出时使用 `tools/web-mobile-release-build.json`；iOS 配置入口为 `tools/ios-preview-build.json`。原生发布仍需完成下述独立验收。

## 四台柜机

| 模式 | 基础玩法 | 专属机制 |
|---|---|---|
| GOLDEN OTTER | 3×3，中央一条水平线 | 失败盘面出现 WILD 后，首个 WILD 所在转轴向下轻推，最多两次 |
| MOON RABBIT | 5×3，固定 243 ways | 第一列出现 WILD 后，向右移动的 WILD 带来四次重转 |
| STAR FOX | 5×5，五个以上正交相邻图案 | 中奖图案消除落下，额外落下采用 1×、2×、4×，最多三次 |
| CLOUD ELEPHANT | 5×3，二十条固定赔付线 | 三个以上财宝飞艇触发锁定货舱；新增货物重置剩余重转次数，总计最多八次 |

规则、赔付表、示意图与引擎一致。飞艇在前三个模式不参加普通赔付，最后一个模式用于货舱。所有投注档位沿用相同抽样分布，不因投注额改变中奖概率。

## 完整流程

- 登录、注册、游客、年龄/协议确认、隐私和帮助；账户隔离、退出和删除入口。
- 初始真实资源加载、四个主题进入场景、进度与失败重试/返回。
- 四入口同屏的空港大厅，选中金色反馈、连续双向切换、中央登船按钮。
- 四模式下注、连续向下转轴、逐轴落定、AUTO、规则、声音、记录、返回。
- 普通奖与 BIG / SUPER / MEGA / EPIC；BIG 以本轮总返还严格大于实际下注为界。演出在柜机内衔接，金币飞往实际余额位置。
- 第五/第十个已结算付费回合的入门补助单独列项并披露，不伪装成自然转轴中奖，也不混入自然概率统计。
- 商店、签到/每日奖励、邮件、示例排行、账户、16个头像及五种语言；默认英语。
- 永久航程：四个港口分别完成 3 / 8 / 15 / 24 个已结算付费回合，领取 400 / 800 / 1200 / 1600 金币；四段领完后一次领取 3200 金币。跨天保留，账户隔离，不能重复到账。
- 四位角色有局部关节动作、眨眼与招财姿态；稳定根节点，不用整图扩张制造运动。大厅与柜机有错峰材质光泽和环境反馈。
- F44 编写的采样乐器航行配乐与分级反馈；静音优先、切换不重复叠播、后台暂停；支持减少动态。

预览内的本地账户和示例排行不代表真实联网服务。未接通 Apple 登录或 StoreKit 时明确提示不可用，商店不能凭点击发放虚构购买金币。
