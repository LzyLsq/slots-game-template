## 成品范围

主题为明亮云海上的财富空港。四座登船岛同屏，大厅、柜机、服务页、登船加载保持统一的象牙白、黄铜、蓝宝石和云海材质。四位卡通船长属于柜机顶部结构，有眨眼、头部和独立关节动作，不依赖整张图片伸缩。

| 模式 | 传统 slot 基础规则 | 专属机制 |
|---|---|---|
| Golden Otter | 3×3 中央一线 | 无奖且出现 WILD 时，第一根 WILD 转轴向下微调，最多两次 |
| Moon Rabbit | 5×3 固定 243 ways | 第一轴 WILD 触发四次重转，WILD 逐轴向右移动 |
| Star Fox | 5×5 五个以上正交相邻成组 | 最多三次追加掉落，倍率依次 1×/2×/4× |
| Cloud Elephant | 5×3 二十条赔付线 | 三个以上飞船锁定货舱，三次重转，新货重置次数，最多八次 |

包含登录、注册、游客、协议确认、条款/隐私/帮助分页、初始加载、四模式加载和柜机、商店、奖励、排行、账户、邮件、头像、语言、声音及规则。永久航程按四港口已结算付费回合累计，3/8/15/24 回合分别可领 400/800/1200/1600 金币，四段领取后可领一次 3200 宝箱；跨天不清零，账户隔离。

普通中奖与 BIG/SUPER/MEGA/EPIC 均保留。回报严格大于实际扣除的下注才进入 BIG 或更高级别。入门第五/第十回合补助独立列项，规则披露；不把补助当作自然概率数据。钱包先完成原子结算，演出只呈现结果，不能重复派奖。
