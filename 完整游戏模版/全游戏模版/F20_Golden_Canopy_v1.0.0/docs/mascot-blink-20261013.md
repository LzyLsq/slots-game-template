# F20 角色眨眼与接缝修复

旧动画将背景和角色切开，再移动头部、耳朵和全身网格。边缘与固定背景错位时容易出现裂缝。本次固定绘制完整原画，不再使用这套角色切图和网格变形。

- 大厅四个主题角色：保留身体、耳朵和场景，只叠加准确注册的局部眼皮。
- 松鼠、兔子、鸟三个柜机角色：同样使用完整 tall 原画加局部眨眼。
- 珍珠柜机乌龟：原画已经闭眼微笑，保留表情，不叠加假眨眼。
- 半闭、闭眼、半开合计约 165ms，间隔 3.5–7 秒，角色不同步，少量双眨。
- 减少动态效果开启、页面退场或进入后台时，眼皮补丁隐藏，恢复完整原画。
- 新眼皮图集 1024×512 RGBA，解码约 2MiB，所有眼皮帧复用，无每帧节点创建。
- 复用项目已有闭眼绘画做局部裁切和颜色对齐；未改写原画。
- 登录、内购、签名、支付商品、音乐与游戏中奖逻辑不属于本次修改范围。

交付仍然是 Cocos Web + WebP + 原生 Xcode 壳。桌面与仓库的 `WebP_IAP_20261010/F20_Golden_Canopy_OC_StoreKit2_Xcode` 同步更新；旧 Web 文件夹保留于桌面「F20_眨眼修复前备份_20261013」前缀目录。

回归检查：

```sh
node --import tsx tools/canopy-blink-test.ts
```

仓库 `tools/lively-optimization/verify-f20-blink.mjs` 检查四个大厅主题、四个柜机、开闭眼截图、进入/退出、真实 SPIN 操作、后台和减少动态效果策略。`sync-f20-blink.mjs` 是本轮专用交付脚本，检查原生文件与音乐文件哈希后，只更新 F20 Web 构建并保留备份。
