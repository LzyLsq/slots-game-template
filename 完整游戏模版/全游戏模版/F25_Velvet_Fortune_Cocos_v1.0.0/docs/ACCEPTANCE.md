# F25 验收要求（本会话）

- 真正 Cocos 工程；F25 独立原创资源，不复制前作主题图。
- 柔和喜庆、财富感；金属与珐琅有厚度，装饰与柜机使用一致的光向。
- 四套传统 slot 规则明确独立；显示倍率、线数与结算一致。
- 转轴向下连续卷动，速度连续、逐轴制动、落停回弹；符号对应主题、裁剪准确。
- SPIN 居中突出；AUTO、加减键分区明确，按钮有固定底座和独立按压键面。
- 保留机柜原位普通奖励提示、分级大奖、免费旋转；动效不遮挡文字与操作。
- 登录方式、注册、同意协议、隐私、帮助、游客和账户存档隔离完整；真实授权不冒充接入。
- 大厅、排行、奖励、商店、账户保留可用交互和动态反馈；签到日期清晰。
- 加载条、转场无黑闪；手机尺寸不重叠、不溢出；支持语言、声音和动效开关。
- 减少整张图片摇摆、矩形全屏扫光、悬空贴纸；光落在具体灯位和边框。
- 以真实运行画面和交互为准，保留测试证据；桌面测试不能冒充真机/发行验收。

本轮重点：S05 原工程实际运行与代码对照、卷动连续性、暖色转轴内衬、物理按键层次。
