# F25 完整体验与独立发布检查

更新：2026-09-20。本文件区分制作目标、已实现项目和发布待验项。

## 本轮完善

- 大厅入口采用清晰的奶油色文字，与自然渐深的肖像底部融合，避免红金小字与角色装饰混杂。
- 附属页面使用连续衬里与侧边嵌线，奖励页改为共同宝匣分隔结构；今日格保留柔和强调与明确日期状态。
- 四模式保持中央 SPIN，以主题底座刻纹作区别；转轴上下曲面和侧缘阴影加深，保留向下滚动、回弹及独立中奖相框。
- 模式加载条根据所需资源完成数更新；缓存命中不强制播放固定假进度。完成态与淡出转场分开，失败清理遮罩并提示重试。
- 加入原创 24 秒循环室内乐音轨，默认声音设置不变；游戏中降低伴奏音量，关闭声音或退后台停止，返回按设置恢复。原点击、旋转、停轮、普通奖与大奖声音保留。
- 取消触摸取消事件触发大厅切换，避免中断手势被算作切换。
