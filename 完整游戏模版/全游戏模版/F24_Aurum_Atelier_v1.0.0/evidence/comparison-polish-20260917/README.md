# F24 对照完善 · 2026-09-17

## 对照范围

查看本地 F13、F14、F15、F17–F23 的历史大厅/柜机截图，以及 S05/S06/S07 的按钮、中奖和特效代码。本地此目录未找到 F16。历史截图用于观察布局与美术，不能代表这些项目今天的全部运行状态；本轮实际修改、浏览器验收仅针对 F24。

## 本轮完成

- 保留大奖原美术，用独立 Sprite 材质对背景边缘做透明羽化，消除上一版矩形深色硬边；标题、金额、按钮不使用羽化材质。演出仍使用前一轮已修复的整体淡入淡出。
- 结算后只对当前可见盘面的真实有支付获奖格保留静态角标，下次转动、换盘面清理。特色玩法最终盘面与历史中奖盘面不一致时，不错误标记旧格子。
- 修复公共按压函数截断材质参数的问题：四种柜机压缩比例分别 .970/.985/.940/.960，原来全部被截断为 .940。

## 验证

- TypeScript 检查及 Cocos web-mobile 构建通过。
- 400 个生成回合测试最终可见中奖格、盘面不一致和未获奖时不标记；原精确金额和封顶结算测试通过。
- 实际 Web 构建测试四种按钮按压、拖离取消操作、中奖角标保持超过 2 秒、下次转动清理，零页面异常。该测试发现并修复了 Cocos 构建对 Set 展开的兼容问题。
- 320×568、414×896，5 种语言、10 个页面共 100 个布局检查：没有检测到越界或过小字号。16 条触摸流程包含四种模式转动、规则开关、返回及服务页切换；无运行异常。
- 大奖进退场透明度、金币路径、精确长金额、连续点击保护、减少动态模式通过，实际检查了大奖融合效果和转轴角标截图。

## 证据说明与边界

retained-win 图片是用真实数学模型的获奖盘面进行的视觉夹具测试，未实际扣款/入账，底部余额和 WIN 不是该夹具的结算记录。第四模式测试基础获奖盘面，正式结算保留提示只对应最后实际盘面。final-win-long 是超长金额排版夹具，并非承诺可赢金额。自动文本检测不等于所有文字在所有设备都已人工验收；本轮没有实体 iPhone 性能测试，也不据此声称 App Store 上架就绪。

## 比较结论

F24 可保留现有大厅的柔和色彩、手工作坊陈列和四种独立柜机。旧作值得借鉴的是柜体内嵌的控件、克制的金属反光、明确的中奖反馈，而不是统一复制布局。本轮优先解决演出拼贴感、中奖反馈易消失和按钮材质手感失效，没有修改赔付规则或商店定价。
