# F43 · Golden Symphony / 黄金交响殿堂

独立原创的财富音乐剧院；暖金舞台、香槟石材、红木与宝石乐器。四个乐师吉祥物自然倚在柜机顶部：猫指挥、猫头鹰竖琴师、狐狸铜管手、兔子鼓手。主题视觉素材通过用户授权的本机 CC Switch 图片接口重新生成；Apple 标准标志单独保留。128 张主题图片均与 F40 基线不同，详见[资源对照](asset-baseline-comparison.json)。

| 范围 | F40 基线 | F43 实现目标 |
|---|---|---|
| 世界 | 河畔灯会四座福楼 | 一座黄金剧院、四个乐团宝库 |
| 大厅 | 福楼入口与每日印章 | 四入口乐团舞台、可保存的三幕乐章册 |
| 金弦 | 10 线、粘性免费转 | 15 线、五次粘性免费转 |
| 蓝宝竖琴 | 变动行高 ways | 固定 243 ways、三轮宝石音符锁定重转 |
| 红宝铜管 | 6×4 任意位置计数 | 4×4 四邻接集群、连锁掉落倍数 |
| 珍珠节奏 | 双 3×3 独立盘 | 单 3×3 五线、三次神秘符号免费转 |
| 成长 | 每日五次四模式印章归零 | 永久乐章收集、三幕曲目进阶、四乐团组成终场阵容 |
| 视听 | 灯笼与民族拨弦 | 指挥动作、琴弦/铜管/鼓台结构，温暖爵士交响配乐 |

保留可靠的登录、余额、结算、协议、商店、签到、邮件、多语言和错误恢复逻辑。新手福利独立标记并记录于结算，不伪造自然中奖。BIG 为赢额严格高于本轮扣除的下注；保留普通/SUPER/MEGA/EPIC。

预览是 Cocos 的浏览器构建。iOS 真机、Apple 登录、StoreKit、签名和 App Store 审核属于单独验收，尚未验证。
