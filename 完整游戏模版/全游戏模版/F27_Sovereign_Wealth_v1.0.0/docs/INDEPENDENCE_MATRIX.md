# F27 Sovereign Wealth — 独立产品差异矩阵

更新日期：2026-09-21

F27 是皇家财富庄园主题的独立传统 slot 产品。代码可继承已验证的安全存储、滚筒生命周期与页面恢复方法，但品牌、美术、页面组织、柜机、符号、玩法组合、加载场景和奖励节奏重新设计。

| 维度 | F27 方案 | 与 F13–F25 的实质差异 |
|---|---|---|
| 世界观 | 日落皇家财富庄园：铸币厂、玉石宝库、钻石锻造与皇冠转轮厅 | 不使用海港、列车、神灯、天宫、庆典棚或旧宫殿走廊结构 |
| 大厅 | 同一圆形金库空间中的四个实体入口，入口直接属于建筑 | 不使用四张普通卡片或仅换色轮播 |
| 成长目标 | 收集四枚 Sovereign Key，点亮中央皇冠金库 | 不复制既有作品的旅程记录或签到叙事 |
| Royal Mint | 3×3、5 条固定线、Wild、失败局可触发一次机械 Nudge | 小型步进线机，强调机械停轮与受控微调 |
| Jade Treasury | 5×4、1024 ways、整列扩展 Wild | 不依赖 paylines 或 cluster |
| Diamond Foundry | 6×5 cluster pays、5 个起奖、连续消除、逐级倍率 | 以相邻集群和重力补位为核心 |
| Crown Wheel | 5×3、20 条固定线、3+ Wheel Scatter 触发财富转轮 | 以正常结算触发选择/转轮奖，不使用 hold & spin |
| 柜机 | 红珐琅铸币机、玉石亭阁、钻石锻炉、木质皇冠转轮机 | 四台结构、屏幕比例、灯饰、按钮底座和反馈均不同 |
| 加载 | 四个模式各自的场景、规则摘要和真实资源进度 | 不以同一加载页只换标题与颜色 |
| 服务页 | 皇家财富长廊：商店、奖励、排行、账户分别用陈列台组织 | 不呈现通用网页表单或统一圆角卡片堆叠 |
| 视听语言 | 自然黄金、象牙石、胡桃木、红丝绒、玉与钻石；柔和喜庆 | 避免旧作海洋珐琅、强硬碎光和突兀纯色底 |

## 不能删减的完整范围

- 初始加载、登录、游客入口、协议与隐私入口。
- 大厅、四模式专属加载、四台柜机、规则、自动旋转、声音与返回恢复。
- 商店、每日奖励、邮件、排行、账户、头像、语言和余额互通。
- 四模式普通中奖标识与大奖演出；结果必须来自真实结算。
- 小屏、常规手机、长文本、快速连点、重复进出、旋转后返回的验收。
