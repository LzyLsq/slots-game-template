# F27 发布验收门槛

更新日期：2026-09-21

## 本地产品验收

- [ ] 登录首屏在 320×568、390×844、414×896 内无需整页滚动。
- [ ] 所有按钮可触达；协议、隐私、游客、账户退出和未接通 Apple 登录状态准确。
- [ ] 四个大厅入口可识别，连续切换、快速反向和重复进入不锁输入。
- [ ] 四套模式加载反映真实资源状态，缓存命中可快速完成，失败可重试或返回。
- [ ] 四台柜机的屏幕、滚筒、控制台和背景形成完整空间；转轴不越过开口。
- [ ] 四种规则、赔付说明和引擎一致；下注、扣款、派奖、恢复待结算轮次不重复。
- [ ] 普通奖逐格金色相框可见；大奖演出完整进入、停留、退出并恢复控制状态。
- [ ] 商店、奖励、邮件、排行、账户和柜机使用同一余额；示例排行明确标记。
- [ ] 默认英语；中文、西班牙语、日语关键长文字不溢出、不重叠、不被遮挡。
- [ ] 观察完整转轴、停轮、回弹、待机、扫光、中奖和转场过程，不以静态截图代替。

## 平台验收（本地完成不能替代）

- [ ] 独立 Bundle ID、签名、版本、图标、启动图和设备方向。
- [ ] 正式 Sign in with Apple 状态；未接通时不提交伪按钮。
- [ ] StoreKit 商品、购买、恢复购买、退款和重复回调真机测试。
- [ ] 隐私清单、隐私政策、支持地址、年龄分级和素材权利记录。
- [ ] iPhone 真机性能、后台音频、内存、弱网和崩溃检查。
- [ ] App Store 元数据、审核说明、4.2/4.3 差异材料及实际审核结果。
