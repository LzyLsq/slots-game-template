# F34 分层财富庆典演出

日期：2026-09-30。预览版本：`f34-grand-wealth-20260930`。

本轮落实“演出动画豪华夸张一点，特效多一点”，增强四台柜机的 BIG、SUPER、MEGA、EPIC 获奖演出。保留四个主题房间、已确认柜机与吉祥物、上一轮 44 条欢快喜庆配乐与反馈音效、真实结算及奖级阈值。

## 实际改动

- 金币由两层升级为三层：大小金币连续喷泉、精确金额揭晓时的抛洒，以及揭晓后 0.65 秒开始的第二波抛洒。两波一次性金币在原有 2.5 秒停留内完成，不延长等待。
- 所有金币从财宝处出发；不同路径向内外抛散，表现腾空、翻面、旋转、回落和渐隐，避免挤成相同轨迹的金币链。
- 两侧财宝增加羽状柔光扇和底部金色反光，与两段高潮同步展开。光效位于金币及文字后方，没有整屏闪白或镜头缩放。
- 每八枚飞行金币配一处局部材质闪光，宝石与金属饰边反射呼应高潮，金额底座的金色肩部增加揭晓高光。
- 标题新增字形遮罩内的揭晓扫光；收敛叠加亮度以保留字形。标题及金额的位置、大小固定，不向玩家突脸。
- 提前揭晓不跳动视觉时钟；再次点击、自动退出、背景暂停、静音及降低动态保持可用。降低动态不创建新金币或动态光扇。
- 使用本工程已有高质量金币与光学图片，在 Cocos 中编排；本轮没有生成图标、替换柜机图片或重新作曲。

## 验证

- 类型检查、演出与旋转金币边界测试通过。四档、四主题、两种比例均验证：金币实际旋转后的包围范围不进入标题说明、金额及收取按钮；两波一次性抛洒在原有 2.5 秒停留内完成。提前揭晓和自动揭晓均有两段光效高潮。
- Cocos Creator 3.8.8 的最终 `web-mobile` 构建完成；编译文件包含最终独立抛散轨迹、第二波金币、光扇和字形扫光。CLI 在本机返回 36，因此同时核实完成日志和产物内容，没有仅凭退出码判断成功。
- 7 个实际运行案例通过：四主题 BIG（390 × 844）和小屏 SUPER / MEGA / EPIC（320 × 568）。检查入场、两波金币实际可见、金额与标题稳定、提前揭晓、快速双击退出、自动完成、余额结算、普通奖与无奖后续轮次、静音、退后台/返回、音频清理和返回大厅；浏览器错误均为空。
- BIG 和 EPIC 完整录制覆盖待机、旋转、入场、计数、第一波揭晓、第二波金币、自动退出及大厅音乐切换。视频是实际 Cocos Canvas，音频是同一时钟采集的实际游戏 WebAudio；保留上一轮 44 条喜庆主题音乐与音效，没有后配音。
- Pearl BIG 使用隔离测试上下文的真实引擎 seed 27：下注 80、总返还 87。Crown EPIC 使用隔离测试奖级 fixture：下注 80、总返还 12,083。fixture 不改变生产随机源，也不能用作自然中奖频率证据。
- 降低动态检查通过：不创建新金币与动态光扇，吉祥物稳定，转轴及立即揭晓可用，声音与清理正确；这些结果来自独立 reduced-motion 案例。
- 已回看连续入场、计数、两段高潮及退出的录制抽帧，并核对四主题及小屏截图，未见文字遮挡、标题突脸、整屏闪白或退出残留。静态图用于构图，完整录制用于时间过程。
- 额外截图会阻塞录制中的浏览器合成，已将它从默认连续录制中分离，截图由运行检查独立保存。最终重录的 BIG / EPIC 帧时钟中位数均为 16.7 ms，95% 分位分别为 16.8 / 16.7 ms，均没有超过 50 ms 的间隔。这是本机桌面采样，不能代替移动实机性能验收。
