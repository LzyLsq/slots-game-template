# F34 吉祥物动作与接触位置打磨 · grounded-v5 · 2026-10-09

本轮保留 [coherent-v4 的完整角色原画与同源肩部结构](guardian-coherent-20261009.md)，调整 Pearl Loom 天鹅和 Crown Foundry 狮子的动作与脚底接触影。柜机原画、角色资源、控制台布局、结算、奖级、演出及已调柔的音乐没有改动；Coin/Sapphire 的既有动作保留。

## 修改内容

- 天鹅改为缓慢展翼、短暂停留、柔和收回。羽翼小动作与展翼曲线分开，减少连续拍打和整张角色摇晃的感觉。
- 狮子改为抬爪后两次猫科招财动作，再自然放下；每轮动作开头和结尾的速度、加速度连续。
- 期待与庆祝使用独立的渐进响应。庆祝不再瞬间放大整只角色；呼吸纵向缩放从旧版最多约 2.8% 收至本轮约 1.1% 的理论上限，主体倾斜也降低。活动爪/翼承担主要可见动作。
- 按各只脚及珍珠底座的实际落点分别设置柔和接触影，保持纹理比例。三处影子固定在原画底座上，置于身体之后；不再用画布中心的一块影子代表所有落脚位置。
- 开启 reduced motion 时主动还原角色姿态和比例，避免在庆祝或展翼姿势停住。

脚底检查指身体的支点固定，不代表呼吸期间每个脚趾像素完全不动。动作仍为 Cocos 中同源图层的关节运动，不能把它描述为全骨骼三维角色。
