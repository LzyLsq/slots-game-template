# F34 奖励演出衔接修正 · 2026-09-30

本轮响应“演出不要是贴纸突脸，太突兀”。保留四主题财富房间、艺术图片标题、普通奖与 BIG / SUPER / MEGA / EPIC、真实结算及上一轮主题音乐，调整入场、画面运动和退出。

## 修改

- 完整柜机始终作为演出后方场景，财富房间用 0.85 秒连续渐入。不再先把柜机装饰和控制台淡没，再创建演出。
- 标题从原 970×345 包围盒调整到 800×330 内等比例显示，固定位置和尺寸；取消扑面放大、弹性过冲和上下漂浮，保留字形内扫光。
- 标题、说明、金额、提示和领取按钮依次渐显。数字定格不再缩放，珠宝反光改为柔和脉冲。
- 金币密度减小，只在宝藏附近起落，路径保持在金额底座上方，不穿过金额或按钮。
- 点击揭晓金额时保持视觉时钟连续，金币和反光不会跳到另一阶段。快速双击退出会先停止入场 tween，再淡出，避免入场与退出竞争。
- 退出时恢复柜机提示和工具栏，停止遗留动画与演出声音。中奖金额仍只结算一次。

- 提前揭晓、入场快速双击退出、自动退出、静音、退后台/恢复、返回大厅和声音清理检查通过。没有重复入账、遗留遮罩或所测案例的浏览器错误。
