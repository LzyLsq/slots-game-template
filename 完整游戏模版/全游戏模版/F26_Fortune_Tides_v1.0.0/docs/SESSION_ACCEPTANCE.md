## 本轮修正的实际缺陷

- 四柜机共用同一符号图集。
- Reef的0.855等赔率被显示为0.86，误导实际赔付计算。
- 奖励金币粒子从数字前穿过。
- 320×568英文大厅牌匾标题过高。
- 规则用符号编号不直观；新增图片与名称对应的作用图例、每模式一句话中奖说明。
- 同时中不同符号时，ways连接不能跨奖组；散布无需连线，取消误导性的邻接线。
- 存储失败时后台仍声称已保存；现在依据实际持久化状态提示。

## 证据边界

自动测试覆盖数学、交易和动画生命周期，不等于美术观感认证。浏览器截图与帧时间不能证明iPhone真机持续帧率。普通奖和大奖应通过真实引擎结果、账本增量与演出同时验证，不能用调试预览冒充；本轮结果见 `ACTUAL_AWARDS_QA.json`。规则家族不同并不等于保证商店审核通过。
