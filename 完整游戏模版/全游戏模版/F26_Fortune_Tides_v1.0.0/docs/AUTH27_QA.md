# F26 固定一屏登录验收

日期：2026-09-20。本记录替代 AUTH26 中长页面布局的描述。

## 本轮改动
- 入口页固定一屏，保留登录、注册、游客、协议确认、条款、隐私、语言和真实服务状态。
- 登录与注册分别显示专注表单，返回按钮回到入口，避免所有内容挤在一页。
- 条款、隐私与账户帮助在独立弹窗阅读。
- 语言箭头随选择框定位；同意协议后撤下旧提示，避免遮住后续表单。
- 保留当前船长舱室美术与主题按钮。

## 验证
- 320×568、390×844、414×896；英语、简体中文、繁体中文、日语、韩语；入口/登录/注册共45组截图与布局检查。
- 文档及登录容器无滚动溢出；检查可见控件边界，并查看小屏英文入口及日语注册最终截图。
- 协议未同意时阻止进入；注册、密码显示、返回、退出后重新登录、错误密码、游客进入及四类说明弹窗通过浏览器交互检查。
- 浏览器未报告脚本错误；48项自动测试通过，静态构建及 iOS 网页资源同步完成。
- 截图：screenshots/auth27-*.png；布局数据：AUTH27_QA.json。
