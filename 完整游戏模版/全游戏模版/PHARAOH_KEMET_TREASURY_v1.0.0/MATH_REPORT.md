## 每日幸运转盘

转盘每天一次免费机会，先通过 Web Crypto CSPRNG 按下表权重选择唯一格子，再由同一个格子反推顶部指针的最终角度并结算；动画与入账不再分别随机。单次期望奖励为 2,745 试玩金币。

准备中的结果会复用同一 `spinId`，结算记录按 `spinId` 幂等校验，重复点击或重复结算不会二次增加余额；待结算金额还必须与对应格子配置一致。

RTP 是长期统计值，不保证单次或短期结果。正式商业发布前仍需扩大到至少一亿局仿真、做分布/波动率/最大暴露验证，并交由目标市场认可的独立实验室认证。
