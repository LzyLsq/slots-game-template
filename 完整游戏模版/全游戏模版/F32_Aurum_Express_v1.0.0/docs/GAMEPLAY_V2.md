# F32 游戏规则与经济说明

本文件描述当前《Aurum Express》实现，而不是前代模板。四个柜机共享金币钱包，但采用不同的基础中奖判定和各自的免费特色回合。具体赔率以游戏内 RULES 和代码中实际结算为准；旧存档使用的内部 ID 不改变。

| 柜机 | 内部 ID | 基础盘面 | 特色回合 |
|---|---|---|---|
| Roulette Rail | `coin-carousel` | 5×3，243 WAYS | WILD 在本转轴内上升，最多三步；只赔付增长部分 |
| Golden Sleeper | `lantern-vault` | 6×5，五枚以上相连成簇 | 已赢格变 WILD 后重新计算，只赔付增量 |
| High Roller | `lucky-parade` | 6×5，八枚以上任意位置同符号成组 | 三枚 Scatter 触发五次免费回合，每回合最多三次额外下落 |
| Jackpot Engine | `celestial-mint` | 5×3，固定赔付线 | 最多四次下落，倍率 1×、2×、4×、8× |

下注档位为 30、80、180、400、500、900 虚拟金币。起始钱包、签到、邮件、轮盘和成就由服务层与当前存档配置决定。Web 预览的商店**不能扣费**，只有有可用原生购买桥接与服务端校验的发行版本才能购买。所有奖励是虚拟金币，不能提现。

普通奖、大/超级大奖为不同演出档位；新账户前五次成功结算的旋转会至少遇到一次迎宾超级大奖（不计取消或失败的旋转）。此规则独立于自然概率，不能把模拟的自然 RTP 用于说明迎宾前五局。数学验证见 `tools/primary-test.ts`、`tools/intro-jackpot-test.ts`、`tools/rtp-simulation.ts`；各份模拟只是抽样，不是第三方认证。

发行前仍须接入真实发行主体、原生登录与支付、生产服务和苹果真机测试，详见 `f32-release-status.json`。
