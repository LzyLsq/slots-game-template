- 画布：单物体、正方形、透明背景（服务支持时）；禁止在完整 UI 图中裁切符号。
- 缩小辨识：150 px 下保留强轮廓，细节线宽不低于缩放后 2 px。

## UI 与动态光泽

- Idle：背景星尘 6–12 秒漂移、卡片扫光 8–12 秒一次、按钮环光 4 秒一圈。
- Spin：转轴框能量流提升到 1.8×；背景降亮 12%；其他卡片停止扫光。
- Anticipation：Scatter 1.2 秒呼吸、末列减速、边框能量提升到 2.6×；不提前显示结果。
- Win：只激活中奖符号和中奖线；斜向扫光宽度为符号宽 18–24%。
- Feature：允许全屏光环/冲击波，但 0.7 秒内回落到核心信息层。
- Low：关闭背景扭曲，粒子 35%，保留中奖扫光。
- Medium：标准粒子、视差和扫光。
- High：完整多层视差、粒子 100%、Feature分层光环；仍不启用永久全屏模糊。
