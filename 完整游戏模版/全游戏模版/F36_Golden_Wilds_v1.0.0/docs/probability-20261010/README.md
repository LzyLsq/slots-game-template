# F36 中奖概率与结算核查 · 2026-10-10

确认并修复了锦鲤共用 WILD 的重复计奖问题，以及自然返还率与 96% 配置目标之间的偏差。保留四模式已有的转轴分布和规则差异，通过赔付系数校准返还金额；没有增加调试强制中奖或调整转轴抽取频率。原有吉祥物、动画、美术、柜机遮罩和演出分级保持本次修改前状态。

## 三个不同指标

- **有返奖率**：单轮包含基础与奖励玩法的总返奖大于零；可能仍低于本轮下注。
- **净盈利率**：总返奖严格大于本轮实际下注，对应 BIG 或更高演出。
- **RTP 返还率**：长期全部返奖除以全部下注。96% RTP 不表示 96% 的轮次中奖，也不保证短期回报。

## 最终自然抽样

每模式 150 万轮，三组独立种子，每组 50 万轮，共 **600 万轮**；下注 180。使用真实 ResultGenerator、实际整数派奖、基础和奖励玩法总返奖。排除新手保底和强制结果。最终验证种子不在赔付校准训练样本中。

| 模式 | 有返奖率 | 净盈利率 | 抽样 RTP | RTP 95% 置信区间 |

| Sun Lion 狮子 | 59.31% | 22.51% | 96.11% | 95.70%–96.52% |
| Emerald Elephant 大象 | 48.03% | 37.45% | 96.16% | 95.85%–96.47% |

四个区间均包含 96% 配置目标，区间半宽均低于 1 个百分点。这是统计相容性检查，不是所有模式精确 RTP 的数学证明。狮子在最终系数修改后使用相同验证种子重新计算；替换前一轮狮子结果，没有重复计入样本。

狐狸只启用一条中线，天然低频高赔付，较长的连续空转属于现有规则的结果。本轮保留该模式区别，没有为了“经常中奖”改成多线规则。枚举狐狸全部 **148,877** 种落点，并计入独立 mystery free spins 的期望；原系数在下注 180 的精确 RTP 是 **94.4703%**，最终为 **95.9810%**。六档下注下精确 RTP 为 **95.9810%–96.0104%**。其他模式的 RTP 目前为抽样估计。

## 修复细节

1. 锦鲤同一盘面每个格子（包括 WILD）仅计入一个付奖组。先选择当前最高赔付组，再排除已获奖格重新判定；剩余有效自然组仍可获奖。瀑布后的新盘面重新判定。
2. 四模式基础和奖励玩法赔付系数分别调整为狮子 `0.4133`、大象 `1.8534`、锦鲤 `1.7933`、狐狸 `1.5916`。符号倍率表仍由同一配置计算，规则显示与结算一致。
3. 原 RTP 检查将 93%–99% 都称为通过，现改为核对该模式目标、95% 置信区间和精度；输出 `TARGET_COMPATIBLE`、`CALIBRATION_REQUIRED` 或 `MORE_SAMPLES_REQUIRED`，后两者返回非零退出码。
4. 锦鲤规则增加五种语言的 WILD 单组归属说明，并修复规则弹窗只读取前两个段落导致补充说明被丢弃的遗漏。补充段落分页显示在赔付表前，赔付页快捷入口随之正确定位。

## 新手保底与演出

保留账户范围内已结算第 5 轮至少 5×、第 10 轮至少 10×的公开新手福利。低于该最低返奖时，使用独立 `newcomer-benefit` 项补足；不改变抽出的图案，不将福利计入自然 RTP，不因换模式重置进度。

演出边界保持：总返奖严格大于实际下注为 BIG，达到 10× 为 SUPER、50× 为 MEGA、100× 为 EPIC。正返奖但未超过下注仍保留普通奖。单独 `debug=1` 不强制中奖；必须显式指定强制结果且只影响对应轮次。
