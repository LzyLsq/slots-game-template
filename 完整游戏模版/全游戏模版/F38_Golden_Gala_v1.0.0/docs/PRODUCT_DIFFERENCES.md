# F38 与 F37 的实质差异

比较对象：交付版 F37 Fortune Caravan 与 F38 Golden Gala。以下是已实现差异，不是 App Review 认证。

| 维度 | F37 | F38 |
|---|---|---|
| 第一模式 | 3×3／5线，逐轴 travelling-WILD 免费重转 | 3×3／5线，WILD整轴扩展，只结算增量 |
| 第二模式 | 5×3／243ways，4次 sticky-WILD 免费旋转 | 5×4／1024ways，6次免费盘，2+WILD条件2×，无sticky |
| 第三模式 | 5×3／25线，4次 mystery 揭晓 | 5×3／20线，原中奖符号两档升阶，固定原中奖线增量 |
| 第四模式 | 5×5连簇，邻格清除及倍率下落 | 5×3／15线，3COIN触发锁币重转，新币重置3次 |
| 大厅 | 地区选择、财富展示与直接PLAY | 2×2建筑展台，四个入口同时呈现，直接PLAY，无模式中间页 |
| 成长 | 5／12／24／40回合及地区条件的旅程站 | 每柜机结算一局获得独立发现印章，600／800／1000／1200收藏奖励 |
| 美术 | 商队／绿洲／集市／港口 | 盛典赌场／皇冠俱乐部／翡翠殿／红宝石舞会／金牛金库；重新生成素材 |
| 角色 | 狮子／大象／孔雀／鹦鹉 | 狮子／大象／女主持／金牛；不同局部招财动作及原画壁龛 |
| 按键 | 旧柜机镶嵌控制台 | 从新柜机原画提取真实金属按键，新材质、座位与动作反馈 |
| 音乐 | 商队场景独立编曲 | 5套新旋律与和声，摇摆／圆号礼乐／竖琴舞曲／三拍舞会，各柜机独立结算配乐 |

保留经过测试的 Cocos、账户与存档隔离、钱包幂等、音频调度、文本适配、Apple／IAP接口合约等基础设施。部分内部模块名保留兼容历史存档，不表示面向用户仍是商队游戏。没有声称所有技术从零重写。

四个模式是同一完整产品内的不同传统 Slots 玩法。**不能只给四模式换 bundle ID 就认定为四个独立可上架产品。** 发行方仍需完成独立定位、差异审查、授权、原生体验与元数据，独立提交状态保持 false。
