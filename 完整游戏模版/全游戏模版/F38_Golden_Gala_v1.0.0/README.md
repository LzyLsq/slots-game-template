### 大厅与收藏

大厅是 **2×2 连续建筑展台**，四个 PLAY 直接进入对应游戏，没有额外模式页。狮子、大象、招财狐狸、金牛具有不同的局部招财动作、呼吸与触摸反馈；角色按原画比例站在预留壁龛，不把图片拉长。

每模式完成一局已结算回合，分别解锁 600／800／1000／1200 金币的收藏印章奖励。账号隔离、幂等领取、独立交易记录，不改变转轴概率。远程模式默认禁止本地发放收藏币，需接入服务端权威接口。

## 音乐与反馈

93 个 AAC：5 首独立场景曲、40 个分级演出及收尾、14 个通用音效、10 个按键变体、24 个柜机专属动作反馈。大厅钢琴／吉他轻摇摆；皇冠柔和圆号；翡翠竖琴／弦乐；红宝石三拍舞会；金库吉他／钢琴摇摆。不同旋律与编曲，不是同一首曲子改速度。

点击、下注、导航、开关、确认有短促材质反馈；各柜机有启动、落轴、轴承循环、入账及特色动作反馈。原速播放、背景压低、场景交叉淡入、隐藏页暂停、限制并发，素材未就绪时即时降级。

原创 MIDI 用本机 CoreAudio 采样乐器离线渲染；短音效离线合成，不是现场乐队或实物录音。技术检查不等于试听或商业授权，见 `docs/ASSETS.md`。

## 运行

本地正式交付目录已附 `build/web-mobile`，无需安装依赖即可预览。Git 仓库保存完整源码、原画、运行素材、测试和截图；`build/`、依赖与编辑器缓存不入库。从 Git 获取后，先按下方「源码验证与构建」生成 Web 构建，再启动预览：

```sh
python3 tools/preview_server.py --directory build/web-mobile --port 6138
```

浏览器打开 `http://127.0.0.1:6138/`。本地验收入口：

- 大厅：`?debug=1&screen=home`
- 柜机：`?debug=1&screen=game&game=crown-club`，也可使用表中另外三个英文 ID：`emerald-fortune`、`ruby-royale`、`vault-reserve`。
- 演出：柜机 URL 加 `&force=super&autospin=0&showcase=1`，**点击 SPIN**。支持 `ordinary`、`big`、`super`、`mega`、`epic`。showcase 保持演出便于截图，点击收取退出；普通奖点击金额条退出。
