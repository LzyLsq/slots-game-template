# F42 固定验收要求

来源：本对话用户要求。冲突时以后续明确要求为准；以下为验收标准，不是通过声明。

## 不能偏离的方向

- 保持真正的 Slots，不改成非转轴游戏。四种模式需有真实规则差异，而非仅替换贴图。
- 同等或更高品质，且区别于前作；以 F20–25 的成品感、S05 的柜机/房间衔接为参考，不复制布局换皮。
- 财富、金币、财宝、博彩主题；成熟精致的3D游戏美术，喜庆、柔和、少幼稚可爱。不使用真人角色。
- 首次语言为英文；中英文切换并记忆。

## 美术与结构

- 柜机、环境、人物、光照、材质、透视和接触关系一致。背景自然延续同一柜机场景，不以大厅底图、虚化、黑影或渐隐遮缝。
- 不拉长柜机；屏幕足够大，实时转轴严密嵌合原画内框，装饰金币和按钮不出框。
- 吉祥物有专属平台与招财意图，融入柜机，不是浮空贴纸。物种动作和大厅/柜机动作有区别；动作需有节奏且持续自然，脚底与接触平台稳定。
- 雕刻、镶嵌、有纹理的按钮使用图像素材，保持厚度和原画比例。重要标题使用高质量图像并有克制的动态效果，不用普通文字冒充标题。
- 符号、头像、人物透明边缘裁切干净，不带黑底、杂边或被错误阴影盖住。
- 大厅原位选择四模式并直接进入，不再用冗余模式选择页面。登录、大厅、排行、账户、商店、奖励不能全部套简单卡片。
- 金币、灯光、水景、角色与按钮可有动态细节，但不遮挡数字、文字和交互，不刺眼、不卡顿。

## 游戏、交互和音频

- 下注位置合理、档位明确；按钮均可用、触区清晰，点按有可见按压和相应音效。
- 登录、商店、每日、奖励、钱包、头像昵称、账本、规则、设置流程互通；不重复扣币或发币。
- 页面/模式切换有滑过感且无黑屏；离开后不得残留加载条、旧角色/转轴、计时器或音效。
- 普通奖金额也必须清晰；返还大于下注归为大奖，普通奖、大奖、超级大奖及更高级奖保留区别。高奖有更豪华的层次、节奏、金币和音乐反馈，不只是放大一张图。
- 前五局内SUPER新手礼遇明确披露与单独记账；不把礼遇伪称自然随机中奖。
- 大厅、各模式BGM与点击、选择、下注、转轴启动/停止、领取、错误、免费功能和分级中奖反馈适合主题。欢快喜悦、柔和、不嘈杂尖锐；切换自然、稳态一首BGM，演出时避让音乐。

## 最终验收方式

- 以实际运行最终渲染为准，不能仅看坐标、概念图或自动测试。
- 多种手机尺寸及横屏检查文字在框内且清晰、元素不相互覆盖、符号不溢出、按钮边缘可点；检查刷新、连点和切换。
- 保存本次真实运行截图；演出预览需明确标记，不得当作随机中奖证明。
- 清理无用临时文件与重复输出，保留必要原画/提示词以便可追溯修改。
- 不伪称商业品质、音频人工试听、iPhone真机或苹果审核已经通过。Web模板与正式原生上架工程应明确区分，原生包装、付款验单、线上服务、授权及最终艺术/试听仍需专项验收。
