## 视觉修正

首轮发现大厅长屏裁切入口、标题过小与柜台读数不够融合。已自然扩绘大厅和柜机背景、重新测量窗口、换成横向字图，并把读数合并到控制台显示区。入口建筑固定，仅金币泉、扫光与局部材质动态；标题独立缓慢浮动。裁切时去除面板游离装饰，避免相邻元素混入。

## 验证边界

这里的截图和流程检查是 Web Mobile 验证，不等于原生 iPhone 认证。生产后端、真实 Apple/StoreKit 配置、签名、法律资料与 Sandbox/TestFlight 真机流程需要发行方接入。本地预览不伪造支付成功或线上对手，不宣称已获 App Store 审核批准。

- 16 个头像均可选择；选择第 16 个头像并刷新后仍保持保存结果。
- 四个柜机标题均使用独立字图，错峰慢浮动；标题运动时转轴与机身坐标保持固定。
- 原生输入框字体、密码隐藏、键盘导致视口变化后的输入保留检查通过。
- 模式加载进度单调递增，并显示 100% 后退场。
