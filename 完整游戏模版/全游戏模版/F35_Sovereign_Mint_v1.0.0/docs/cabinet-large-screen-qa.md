# F35 柜机大窗口验收 · 2026-09-30

## 调整
- 四套柜机的转轴玻璃改为更高的窗口；红宝石五行模式优先接近方形，保留原行列数和玩法。
- 继续使用现有 1024×2304 高清整合场景，不是新生成的柜机图片。Cocos 使用同一纹理的连续五段采样，仅延展玻璃/导轨的两个窄段；顶部、中央装饰段、按钮、寄存器、标题和吉祥物不整段纵向缩放。
- screen、mask、转轴、停轴反光、按钮、AUTO状态与 COINS/BET/WIN 共用同一扩展几何；下方操作区与原图同步下移。
- 短屏自动减少扩展量，优先保留窗口宽度。手机窗口宽度仍至少占视口60%，不以整台柜机过度缩小换取大窗口。
- 调整窗口期间不重建未完成的转轴/结算；空闲后安全重排，保留结果棋盘、WIN及提示，不重新扣款/入账。
