## 1. 不再把同一首旋律变速当作不同配乐

五首 16 小节立体声音轨，拥有各自的旋律、和声、配器、伴奏与 A/B 回答句：

| 场景 | 文件 | 主要实际配器与设计方向 |
| --- | --- | --- |
| 大厅 | `music-lobby.m4a` | 钢琴、颤音琴、指弹低音；轻摇摆 casino lounge，留出操作音的空间 |
| 金狮 | `music-golden-hour.m4a` | 弱音小号、钢琴、低音、颤音琴；温暖金属质感与庄重感 |
| 翡翠 | `music-jade-treasury.m4a` | 琴筝类 Koto 采样、笛、拨弦、弦乐；疏朗五声音阶与招财庭院氛围 |
| 珍珠 | `music-pearl-palace.m4a` | 竖琴、钢片琴、笛、弦乐；6/8 摇曳、柔和水波感 |
| 红宝石 | `music-ruby-revel.m4a` | 弦乐、圆号、竖琴、大提琴；凤凰仪式的宽阔回答句 |

音轨是原创 MIDI 编曲，经本机 `AVAudioUnitSampler` 与已安装 CoreAudio 乐器音色离线渲染，再独立母带处理、编码；不是现场乐团录音。没有下载商业歌曲，没有把乐器音色库随项目打包。效果音以原创的机械/金属/金币声设计离线生成。此来源说明不等于商业授权清理结论。

## 2. 每个动作有自己的声音职责

- 普通按钮：短而收敛的木质接触 + 金属按键声音，不使用长胜利音。
- 下注：齿轮卡位式双击声；导航：轻滑动 + 接触落点；设置切换：短开关声；确认：短金币确认。
- SPIN：机械启动；转轴运行：低声轴承纹理；逐轴落定：短落位声。停止、异常、离开页面时清掉运行循环。
- 无盈利返还/小奖：中性短句，不冒充大奖。
- BIG / SUPER / MEGA / EPIC：按四个主题分别编曲，每档独立的铺陈、上行、配器密度与收束，不把 BIG 音轨直接加速用于其他奖。
- 金币累计与宝箱收束：演出主段和独立 resolve 音轨跟随视觉时间；同一次演出只触发一次收束。
- 领取/继续：关闭演出后才播放金币归拢音。第一次只揭示金额的点击不误播收款。
- 余额不足/保存失败：柔和低音否定反馈，不用报警尖声。

合计 **59 个 AAC 文件，5,983,547 字节**：5 首背景曲、4 主题 × 5 等级 × 主段/收束共 40 段演出、14 个操作/机械/金币效果。

## 3. 混音、加载与生命周期

- 正常浏览器主路径播放解码后的 AAC；文件缺失或尚未就绪时，低层 WebAudio 仅作为即时后备。按钮不等网络，晚到的完整演出不会在中途补播。
- 旧场景音乐约 0.48 秒退场，新音乐约 0.52 秒进入；录音就绪后自动替换首屏后备。渐变、限幅与短房间空间控制叠声，不用每帧几十个 oscillator 堆出演出。
- 中奖时自动压低背景；关闭演出恢复音乐。背景音乐和按钮/中奖音效独立控制，轻触振动另有开关，设置保存。
- 首次用户手势解锁音频；后台暂停并清除声源，返回不补播错过的音符。声音并发有上限，连点去重。
- 同源资源优先加载当前 BGM/首触反馈，最多三路 fetch/decode；解码后的 BGM 最多缓存两首，离开柜机移除旧演出缓存。
- 修复 Cocos 生产转译不展开 Map/Set iterator spread 的问题；生产代码使用 `Array.from`，加入回归断言。修复重复 stop 延长尾音和快速开关复用已停止声源的问题。

## 5. 生成、复验入口

在项目根目录执行（Python 需要 NumPy）：

```sh
node --import tsx tools/compose-soundtracks.ts /tmp/f35-audio-work/scores.json
swiftc tools/render-instruments.swift -o /tmp/f35-audio-work/render-instruments
/tmp/f35-audio-work/render-instruments /tmp/f35-audio-work/scores.json /tmp/f35-audio-work/raw
python3 tools/master-audio.py /tmp/f35-audio-work/raw build-templates/web-mobile/audio /tmp/f35-audio-work/scores.json
python3 tools/audio-asset-qa.py build-templates/web-mobile/audio docs/audio-decode-qa-20260930.json
npm run typecheck
npm run typecheck:server
npm test
```

原始 WAV、临时 score 与编译工具仅放 `/tmp`；交付只保留生成脚本、59 个最终 AAC、manifest 和验收证据。
