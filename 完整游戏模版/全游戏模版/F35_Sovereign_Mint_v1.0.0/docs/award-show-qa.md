# F35 奖励演出与主题配乐验收

日期：2026-09-30

## 奖级规则
以本局实际结算总返还 / 本局实际下注分类，不改变生产赔付或随机规则。
- 0 < 返还 ≤ 下注：普通返还 / 回本，清楚显示金额，采用中性提示。
- 返还严格 > 下注且 < 10×：BIG，大型金币演出。
- ≥ 10×：SUPER；≥ 50×：MEGA；≥ 100×：EPIC。
- 0、1×、1+epsilon、10×、50×、100×和非有限数值均有边界测试。
- 五种语言规则说明、吉祥物响应和奖励分类使用同一门槛。

## 豪华演出
主题宝库 / 高清宝箱、金币喷泉、计币、高光、高潮与独立金额牌使用共同时间轴。首次点击揭示终值并播放高潮，再次点击退出；已结算钱包不会重复入账。普通返还演出保留。

BIG / SUPER / MEGA / EPIC 标题图片来自用户现有 F12 资源，本轮没有成功生成新标题。SUPER 使用的图片实际写作 GREAT WIN，下方清楚注明 SUPER BIG WIN · 10× BET OR MORE。

## 五套原创程序配乐
| 场景 | 节奏 | 配器方向 |
| --- | --- | --- |
| 大厅 | 82 BPM，4/4 | 柔和钢琴、竖琴，安静迎宾 |
| 金狮铸币 | 88 BPM，4/4 | 温暖铜管、钢琴、金属敲击 |
| 翡翠麒麟 | 78 BPM，4/4 | D大调五声音阶拨弦、弦乐、木质打击 |
| 珍珠海马 | 76 BPM，6/8 | 钟琴、竖琴、柔和刷击，潮汐感 |
| 红宝石凤凰 | 94 BPM，4/4 | 庆典弦乐、铜管、框鼓式打击 |

各套具有独立旋律、和声、中奖短句，不是同曲转调。乐器名称描述程序音色方向，实际由 WebAudio 谐波合成、包络、滤波和短混响实现，不是录制乐器音源。

按钮 / 导航 / 下注 / 吉祥物反馈随主题调性与配器；SPIN / 停轴保留机械感。大奖进行时压低BGM，高潮后恢复。音乐与音效独立开关；后台暂停；静音 / 后台期间旧音符不会恢复补播；最多48声源，销毁时完整释放。
