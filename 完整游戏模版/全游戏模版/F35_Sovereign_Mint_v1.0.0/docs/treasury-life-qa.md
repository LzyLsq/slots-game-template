# F35 大厅与柜机动态细节

2026-09-30。本轮只增加环境/互动动效，保留原有音轨、钱包、下注、中奖数学、柜机大屏和关节吉祥物。

## 设计
- 大厅：金币河中有分层翻转金币和沿河反光；四扇宝库门有各自金属珠宝轨迹与低亮度珐琅光晕；中央灯柱有向上金尘。守财狮轻微迎客摆动、点击产生局部金辉与声音。门的触摸反馈保留原有压下响应。
- 柜机：金狮环绕金辉、翡翠向上浮动、珍珠水波轨迹、红宝石上升余烬；沿外侧金属框有连续光点，底部已有财宝堆上有金币弧线及反光。所有粒子使用现有高质量金币与光效位图，不画简陋新图标，不添加漂浮卡片。
- 点击吉祥物、开始旋转、中奖反应触发短而柔和的局部亮度回应；弹窗背景动效降至 28%，完整演出保留原有独立表演。文字、下注、余额、获奖金额、按钮与转轴内没有新粒子。

## 约束与性能
- 大厅和每个柜机新增 62 个可复用位图节点（上限 64），初始化一次。无需在装饰更新循环中创建节点、Tween 或姿态数组。
- 装饰更新为 30Hz；柜机操作和转轴没有改为 30Hz。
- 共享 CabinetGeometry 的柜机坐标与转轴扩展，适配窄屏不会按屏幕绝对坐标错位。
- 页隐藏暂停时钟，异常长帧限步；reduced-motion 模式不创建装饰节点；销毁时注销显示/隐藏监听。
- 逐个测试旋转位图的实际包围盒，不仅检查中心点。已有 245,520 个姿态验证裁剪边界、四款柜机净区和大厅标题净区。
