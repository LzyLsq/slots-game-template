# F25 · Velvet Fortune

原创剧院主题完整本地 H5 Slot 模板，使用 HTML、CSS、JavaScript 与新生成 WebP 美术，无 Cocos、无构建依赖。

## 启动

Node.js 18+，在本目录运行 `npm start`，打开 http://127.0.0.1:5525/ 。默认英语，支持简体中文、繁体中文、日语、韩语。

## 功能

- 访客登录、16 头像、昵称、音效／动态／语言设置、退出保留存档、重置进度。
- 四入口大厅，点击或连续滑动选择；进入柜机有素材加载进度条。
- 中央 SPIN、独立 AUTO 与下注加减、自动停止、余额保护、规则及赔付表。
- 普通与 BIG / MEGA / EPIC 获奖演出，滚动金额、中奖路径、符号高亮、落定回弹、金币雨与到账反馈。
- 七日签到、每日到访礼、一次性邮件附件、演示商店、账本、玩家与模拟角色统一排名。
- 本地备份／恢复、多标签锁、存储失败回滚、中断回合恢复且只结算一次。
- 标题浮动和材质扫光、柜机高光、按钮反馈、页面淡入淡出；尊重减少动态设置，后台停止下一次自动旋转。

## 四套传统 Slot 规则

| 模式 | 规则 |
| --- | --- |
| Crown Classic | 3×3，5 条左起固定线，WILD 替代 |
| Ruby Reflection | 5×3，20 条双向线，每线只付更高方向；SCATTER 独立奖励 |
| Pearl Parade | 5×3，243 ways；含 WILD 的中奖路径翻倍一次 |
| Golden Encore | 5×3，10 条线；3 个不同转轴 SCATTER 触发 8 次免费旋转，中奖提升下一转倍数，最高 5× |

下注档位 50 / 100 / 250 / 500 / 1,000 / 2,500。每回合含免费旋转总奖励上限为总下注的 1,000 倍。细节见游戏内规则和 `engine.js`。结果在演出前确定，特效不修改结果。

运行 `npm test`（17 项通过）；`npm run audit:math` 运行数学抽样。

浏览器验证覆盖 5 语言、4 柜机、320×568 / 390×844 / 430×932 / 768×1024 四种视口，共 80 种柜机配置和 100 种主页面配置。连续 12 次滑动、备份恢复、自动停止、重复领取、异常存储、中断恢复通过。报告和截图见 `docs/`。

`?debug=1` 显式启用 `window.f25Debug`。获奖截图由此预览生成，不代表实际抽奖、不修改余额。正常入口不开放调试接口。数学报告是固定种子抽样，不是认证 RTP。

## 交付边界

这是本地 H5 完整演示模板：访客身份、商店金币和排行榜角色均为本地演示，不含真实支付、Apple 登录或远程账户。金币不可提现。清除浏览器数据会清除进度，可先导出备份。Chrome 自动化检查不等于实体 iPhone 测试或 App Store 上架认证。

美术为本项目新生成与裁切的 WebP，未复用 F20–F23 美术；提示和清单见 `art-prompts/`、`docs/ASSETS.json`。
