- 登录：上半部财神迎宾与聚宝盆，下半部云台登录表单；主登录居中，Apple 与游客为次级操作。
- 大厅：四座仙境以两行两列大入口同屏呈现，点击任意仙境直接加载对应游戏，横向滑动只切换高亮、不触发进入；每座入口下显示点击提示，移除重复的 PLAY NOW。场景不整体晃动，局部光点与标题扫光，建筑底部使用分层接触阴影，选中光晕平滑交接。
- 加载：如意将金币引入聚宝盆，独立真实资源进度条，加载完成才进入；避免黑屏。
- 排行：金榜卷轴与前三甲印章，玩家参与同一积分排序；模拟数据保持说明。
- 奖励：七日祈福环围绕聚宝盆排列，今日、已领取、未解锁视觉分明；独立金印签到与每日宝物领取，盆内触摸触发装饰光点。
- 账户：玉牒身份页，昵称可编辑、16个以上主题头像、统计与设置分区。
- 商店：单件聚宝展台与四枚宝物选择器，切换宝物展示和数量；朱红购买按钮、独立恢复购买入口。触摸宝物触发光点，真实内购未接入时不伪造到账。
- 信箱：奏帖式列表与详情，已读未读、附件领取、防重复到账。
